# 디자인 브리프 — 메시지 게이트 (Message Gate)

> Claude Design 핸드오프용. 기존 AgentParty 제품 디자인 위에 이 기능 화면을 추가한다.
> 전체 기획/데이터 모델은 `docs/MESSAGE_GATE.md` 참조.

## 제품 맥락 (요약)
AgentParty는 로컬 멀티 에이전트 코딩 앱이다. 하나의 **파티**에 여러 **멤버**(각각
Claude Code / Codex 하네스로 도는 에이전트)가 있고, 멤버끼리 메시지를 주고받으며
협업한다. 멤버는 **런타임 모달**에서 모델/추론/권한을 조정하고, 신규 멤버는 **멤버
위저드**(이름→하네스→모델→추론→권한→역할)로 만든다. 권한은 세그먼트형 옵션 칩
(예: Default / Accept edits / Plan / Auto …, 각 칩에 아이콘 + 한 줄 한글 힌트)으로
표현한다.

**UI 카피 관례**: 컨트롤 **라벨은 영문**, **힌트·설명은 한글**. 아이콘은 lucide.

## 이 기능이 하는 일
멤버가 다른 멤버에게 메시지를 보낼 때, 배달 직전 **경량 모델(리뷰어)** 이 "사용자가
정한 통신 규칙"(예: 간결하게 보내라 / 오케스트레이터 거치지 말고 직접 소통하라)을
지키는지 심사한다. 위반이면 **반려**하고 발신자가 다시 쓰게 한다. 리뷰어는 harness/
model/effort를 갖는 "멤버가 하나 더 있는" 개념이다.

규칙은 **파티 단위 전역 규칙**을 기본으로 하고, **멤버가 이를 오버라이드**할 수 있다.
파티 생성 시 게이트는 **기본 꺼짐**.

---

## 그려야 할 화면 4개

### 1) 멤버 게이트 편집 (런타임 모달 내 새 섹션 "Message Gate")
멤버 런타임 모달(모델/추론/권한 편집하는 곳)에 게이트 섹션을 추가한다.

- **on/off — 3-state 세그먼트 토글**: `Inherit`(상속) / `On`(켬) / `Off`(끔).
  - Inherit = 파티 설정을 따름. 현재 파티가 켜짐/꺼짐인지 보조 텍스트로 표시
    (예: "파티 기본값: On").
- **규칙 지시문 — 멀티라인 텍스트 영역**:
  - 편집창을 열면 **파티 전역 규칙이 기본값으로 채워져 있다**(placeholder가 아니라
    실제 값 프리필).
  - 사용자가 편집하면 "이 멤버 오버라이드"가 된다.
  - 텍스트 영역 옆/아래에 **"전역 규칙으로 되돌리기"**(Reset to party rule) 링크·버튼.
    누르면 오버라이드가 지워지고 다시 파티 규칙을 상속(프리필 상태로 복귀).
  - 오버라이드 상태 vs 상속 상태를 시각적으로 구분(예: "Overridden" 뱃지 / 상속 시
    옅은 톤).
- **리뷰어 모델 설정**: 기존 멤버 **모델 선택 UI를 재사용**(하네스 + 모델 + effort).
  - 미설정 시 "설정 기본값 사용" 상태로 표시. 변경하면 이 멤버 전용 리뷰어 모델.
- 규칙이 비어 있으면 "규칙이 없어 심사가 실행되지 않음" 안내.

### 2) 파티 생성 플로우 — 게이트 옵션
파티를 만드는 플로우(또는 파티 설정)에 게이트 항목을 추가한다.

- **체크박스 "메시지 게이트 사용"**, **기본 꺼짐**. 미체크면 그냥 넘어갈 수 있어야 함.
- 체크하면 **규칙 지시문 입력란**이 펼쳐진다(멀티라인).
- 파티 생성 후에도 파티 설정에서 켜고 규칙을 편집할 수 있다는 진입점 필요.

### 3) 설정 → Runtime — 게이트 기본값 (Gate defaults)
앱 설정의 Runtime 영역에, 리뷰어의 **기본 모델 / effort / 하네스**를 고르는 컨트롤.
기존 하네스 기본값(harness defaults) 컨트롤과 나란히 두는 그룹. 권장 기본은 가장
저렴·빠른 모델(예: Haiku).

### 4) 검문 결과 표식 — transcript 배지 / 채널 이벤트
멤버 대화(transcript)에 검문 결과를 인라인으로 노출한다. 3가지 상태:

- **반려 (Rejected)**: 어떤 메시지가 규칙 위반으로 반려됨. 발신자, 대상, **사유** 표시.
  경고성(주의) 톤.
- **강제 전송 (Forced)**: 발신자가 게이트를 우회해 강제 전송함. 우회 사실 + 사유
  표시. 눈에 띄는(무력화 아님을 알리는) 톤.
- **리뷰 실패 (Review failed)**: 리뷰어 호출이 실패해 심사 없이 배달됨(fail-open).
  오류 사유 + "심사 없이 전달됨" 표시. 에러 톤.

작게, 대화 흐름을 방해하지 않는 인라인 배지/칩 형태를 권장.

## 상태·엣지 케이스 체크리스트 (디자인이 다뤄야 할 것)
- 게이트 Inherit / On / Off 각각의 편집창 모습.
- 규칙: 상속(프리필) 상태 vs 멤버 오버라이드 상태의 구분, "되돌리기" 동작 전/후.
- 리뷰어 모델: 설정 기본값 상속 vs 멤버 지정.
- 파티 생성: 미체크(기본) vs 체크 후 규칙 입력.
- transcript 배지 3종(반려/강제/실패)과 사유가 길 때의 처리(펼치기/말줄임).
- 규칙이 비었지만 On인 경우의 안내(심사 미실행).

## 톤 & 재사용
- 기존 권한 세그먼트 칩, 모델 선택기, 런타임 모달의 비주얼 언어를 그대로 따른다.
- 라벨 영문 / 힌트 한글. 과한 신규 컴포넌트보다 기존 패턴 확장을 우선.
