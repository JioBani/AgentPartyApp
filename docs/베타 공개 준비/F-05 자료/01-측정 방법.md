# 01 — 측정 방법

**문서가 아니라 실물을 쟀다.** 웹 문서·`--help` 로 쓴 선행 조사가 실제 UI 와 어긋난 전례가
있어서([06-선행 조사 대조.md](06-선행%20조사%20대조.md)), 전부 실행 중인 프로그램에서 뽑았다.

## 대상과 버전

| 대상 | 버전 | 위치 |
|---|---|---|
| Codex CLI | 0.145.0 | `C:\Users\Dev\AppData\Roaming\npm\codex.cmd` |
| Claude Code CLI | 2.1.226 | `C:\Users\Dev\AppData\Roaming\npm\claude.cmd` |
| Claude Code VS Code 확장 | 2.1.220 | `C:\Users\Dev\.vscode\extensions\anthropic.claude-code-2.1.220-win32-x64` |

측정한 작업공간은 전부 `C:\Project\AgentPartyApp` — **우리 앱이 보는 것과 같은 인벤토리**여야
비교가 성립하기 때문이다.

### 범위 밖

- **Claude Code 데스크톱 앱** — 이 PC 에 설치돼 있지 않다. `AppData\Local\Claude` 에 로그 폴더만 있다
- **Cursor** — 설치돼 있으나 미측정
- **ChatGPT(Codex) VS Code 확장** — 설치돼 있으나 미측정

## 방법 A — TUI (Codex CLI · Claude Code CLI)

터미널 앱이라 DOM 이 없다. **실제 pty 를 열어 띄우고, 키를 주입하고, 화면 그리드를 재구성**했다.

```
node tui-capture.mjs --cmd <cli> --cwd <dir> --cols 80 --rows 25 \
  --step 9000 --key "/" --step 2500 --out shots/x.txt
```

- pty 는 Git 이 함께 설치하는 **`winpty.exe`** 를 썼다(`node-pty` 미설치, 설치는 위험 —
  워크트리들이 `node_modules` 하나를 공유한다)
- `tui-capture.mjs` 안에 **최소 VT 에뮬레이터**를 넣었다. CUP/ED/EL/커서 이동/줄바꿈/
  전각 문자 폭을 처리해 **보이는 화면 그대로**를 텍스트로 복원한다.
  ANSI 원본도 `.raw` 로 함께 남긴다
- 키는 `<down>` `<bs>` `<esc>` 같은 이름으로 주입한다

### 함정 두 개 (재현할 사람을 위해)

1. **MSYS 경로 변환** — Git Bash 가 인자 `/` 를 `C:/Program Files/Git/` 로 바꿔 버린다.
   `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*'` 를 반드시 붙일 것
2. **터미널 크기가 80x25 로 고정된다** — `winpty.exe` 에 cols/rows 옵션이 없다
   (`winpty-agent.exe` 에는 있지만 winpty.dll 의 제어 파이프 프로토콜이 필요해 재구현은 과하다).
   그래서 **"한 번에 몇 행 보이나"는 TUI 에서 확정하지 못했다.** 그 수치는 VS Code 확장에서 쟀다
3. 부팅 시 나오는 프롬프트(Codex 업데이트 안내 · Claude MCP 승인)를 먼저 넘겨야 팔레트에 닿는다

## 방법 B — DOM (Claude Code VS Code 확장)

**육안이 아니라 computed style 실측.** 저장소 관례를 따랐다.

```
node vscode-cdp.mjs      # 격리 프로필로 VS Code 를 --remote-debugging-port=9333 로 띄운다
node probe.mjs list
node probe.mjs eval 3 "<js>"
node probe.mjs type 3 "review"
node probe.mjs key  3 Backspace 6
node probe.mjs shot 0 out.png x,y,w,h
```

- **사용자 VS Code 를 건드리지 않으려고** `--user-data-dir` 을 스크래치패드로 격리했다.
  확장 폴더(`--extensions-dir`)만 실물을 공유한다. 측정 시작 시 VS Code·Cursor 둘 다 미실행 확인
- VS Code 웹뷰는 **iframe 이 두 겹**이다. 바깥 웹뷰 타깃 안의
  `document.querySelector('iframe').contentDocument` 로 들어가야 실제 UI 가 나온다
- 타이핑은 DOM 조작이 아니라 **CDP `Input.insertText` / `Input.dispatchKeyEvent`** 로 했다.
  앱의 실제 핸들러를 타야 필터 동작이 진짜다
- 창 1920x1032, 패널 폭 1272 — **좁아서 생긴 축약이 아님**을 확인하기 위해 넓게 뒀다

### 함정

- `Page.captureScreenshot` 은 **최상위 타깃에서만** 된다. 팝업만 잘라내려면 웹뷰 iframe 의
  오프셋을 더해 최상위 좌표로 변환해야 한다(`348,70` + iframe 내부 좌표)
- 창이 가려지면 스크린샷 호출이 **응답 없이 매달린다**. 수치는 `Runtime.evaluate` 로 따로 뽑아 둘 것

## 재현

```
cd docs/베타 공개 준비/F-05 자료
MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*' node tui-capture.mjs \
  --cmd "C:/Users/Dev/AppData/Roaming/npm/codex.cmd" --cwd "C:/Project/AgentPartyApp" \
  --cols 80 --rows 25 --step 9000 --key "2" --step 700 --key "\r" --step 10000 \
  --key "@" --step 2500 --out at.txt
```

`probe.mjs` 는 `ws` 를 저장소 `node_modules` 에서 가져온다(별도 설치 없음).
