# B-12. 교차 하네스(크로스 라우팅)에 문제가 많다

**판정: ✅ 구현 완료 (2026-08-08 beta-impl) — 잠갔다** · 출처: 사용자

---

## ✅ 구현됨 (2026-08-08, beta-impl)

**제거가 아니라 잠금이다.** 실행 코드는 그대로 있고 **판정 한 곳만** 막았다.
되돌리려면 `crossHarnessLockReason` 이 `undefined` 를 반환하게 하면 된다.

### 착수 전 확인한 두 가지
1. **기존 교차 멤버 0건** — 실작업공간 5곳 7멤버 전수 스캔. 그래서 "기존은 두고 새 선택만 막기" 예외 분기를 **만들지 않았다.**
2. **강제 지점은 3곳** — 생성은 한 곳으로 모이지만 **런타임 변경이 두 갈래**다.

### 판정 규칙 (경계가 이 항목의 핵심이다)
**모델의 제공자가 자체 하네스를 가진 셋(`anthropic`·`openai`·`cursor`) 중 하나이고,
그것이 실행 하네스의 원래 제공자와 다를 때만** 잠근다.

⚠️ **`Backend.kind` 로 가르면 안 된다.** `claude-router` 하나에 **잠글 것(GPT·Cursor 구독)과
잠그면 안 되는 것(OpenRouter·DeepSeek)이 같이 들어 있다.** kind 로 판정했으면 OpenRouter 21개가
통째로 죽는다. **카탈로그 `provider` 로만 판정한다.**

자체 하네스가 없는 제공자(OpenRouter·DeepSeek)의 모델은 claude-code·codex 위에서 도는 것이
**유일한 실행 경로**이므로 교차가 아니다.

### 바꾼 것 (6파일)
| 파일 | 변경 |
|---|---|
| `shared/modelIdentity.ts` | **`crossHarnessLockReason()` 신설** — 판정과 사유 문구의 단일 출처 |
| `core/modelRegistry.ts` | `ModelRoute.locked` 추가 · `addRoute()` 에서 `betaLocked()` 적용 |
| `main/application/partyApplicationService.ts` | `assertNotBetaLocked()` · `assertSessionModelAllowed()` — **생성 · respawn** 강제 |
| `main/engine/localEngine.ts` | `setSessionModel` 강제 (어댑터에 닿기 전) |
| `renderer/workbench/ModelCatalogModal.tsx` · `routes.ts` | `베타 잠금` 배지 (`미지원` 과 구분) |
| `renderer/styles.css` | 잠금 배지는 `warning` 토큰 — 영구 미지원의 회색과 다르게 |

**표시는 기존 메커니즘을 그대로 썼다** — `enabled:false` + `unavailableReason` 은
`unavailableCursorHarnessRoute` 가 이미 쓰던 패턴이다(*"사라지거나 조용히 바뀌지 않고 이유와 함께"*).

**잠금 지점이 `addRoute()` 한 곳**인 이유: 카탈로그·Codex 디스커버리·OpenRouter·Cursor·커스텀
**모든 경로가 이 함수를 지난다.** 나중에 추가되는 경로도 자동으로 덮인다.

덮어쓰지 않는다 — 더 강한 이유를 남긴다.)

### ⚠️ 계측 정정
턴 완료를 "세션이 바쁜 상태를 벗어남"으로 판정했더니 **턴이 시작되기 전에 읽고 나가서**
codex+OpenRouter 가 빈 응답으로 보였다 — 회귀로 오독할 뻔했다. 트랜스크립트에는
`assistant: RUNOK` 과 `turn complete - $0.0363` 이 남아 있었다.
→ **`kind === "assistant"` 블록에 마커가 나타날 때까지** 기다리도록 고쳤다.

### 재검증 방법 (다음 사람이 다시 돌릴 때)
검증 드라이버는 레포에 남기지 않았다(새 테스트 코드 금지 방침). 다시 확인하려면 **실제 앱을
격리 실행**해서 아래를 보면 된다 — 순서가 중요하다. **회귀를 먼저 본다.**

1. 격리 `AGENTPARTY_USER_DATA` + 임시 작업공간으로 앱 기동
   (`scripts/launch-electron.mjs --workspace <ws>`; 포트는 `<ws>/.agent_party_app/instances/` 로 발견).
   ⚠️ `settings.json` 에 `routerBaseUrl`·`routerAuthToken`·`openRouterApiKey`·`deepseekApiKey` 를
   복사해 넣어야 OpenRouter·DeepSeek 턴이 실제로 돈다.
2. **회귀** — `GET /api/models` 에서 `providerId` 가 `openrouter`·`deepseek` 인 라우트에
   `locked === true` 가 **하나도 없어야** 한다. 그다음 claude-code·codex 각각에 OpenRouter 멤버를
   만들어 **실제 턴을 돌린다**(목록에 보이는 것과 실제로 도는 것은 다르다).
3. **잠금** — `locked === true` 인 라우트가 **정확히 12개**인지. 그리고 세 경로가 모두 거부하는지:
   `POST /api/party/members` · `POST /api/sessions/:id/model` · `POST /api/party/members/:name/respawn`.
4. **화면** — 모델 팔레트에서 provider 그룹(`.wb-model-provider-btn`)을 펼치고
   `.wb-model-row` 의 `.wb-model-off` 텍스트를 읽는다. Claude Code 하네스 = `베타 잠금` 7행,
   Cursor 하네스 = `미지원` 34행.

⚠️ **턴 완료를 세션 상태로 판정하지 마라.** `kind === "assistant"` 블록에 마커가 나타날 때까지
기다려라(위 계측 정정 참고). 그리고 마커는 프롬프트에도 들어가므로 user 블록을 세면 안 된다.

### 남은 것
- 문구는 최소한으로 넣었다(`베타 잠금` + 한 문장). **정교한 표현은 D-02 용어표와 함께** 다듬는다.
- **잠금 해제 = `shared/modelIdentity.ts` 의 `crossHarnessLockReason` 이 `undefined` 를 반환하게
  하는 것.** 표시(`modelRegistry.betaLocked`)와 강제 3곳은 전부 그 함수 하나를 부르므로 그 외에
  손댈 곳이 없다. 실행 코드는 처음부터 건드리지 않았다.
- 잠금 해제 전에 이 항목이 원래 기록한 결함들([#4] 큐 데드락 · [#17] 없는 세션 resume)이
  재발하지 않는지 확인해야 한다. **잠금은 그 결함들을 고친 것이 아니라 가린 것이다.**

## 결정

> **베타에서는 교차 하네스를 잠근다. 고치는 것은 후순위.**

앞서 검토한 ⓐ(고쳐서 낸다)·ⓑ(실험 표시)·ⓒ(뺀다) 중 **ⓒ에 가깝되 "제거"가 아니라 "잠금"** 이다.
코드를 들어내지 않고 **선택 경로만 막는다.** 나중에 고쳐서 다시 열 수 있어야 한다.

### 근거
- 결함이 이 경로에 몰리는 것이 우연이 아니다 — `[#4]`(턴 상태 고착 → 큐 데드락) ·
  `[#17]`(없는 세션 resume) **둘 다 교차 교체 경로**에서 터졌다.
- **양쪽 하네스의 변경에 동시에 노출**된다. 조합 수만큼 경우의 수가 늘어 비용이 예측되지 않는다.
- 지금 **증상이 특정되지 않은 상태**라 고치기를 택해도 착수할 수 없다.

### 잠글 대상 — 기능정의서 1-12-2 가 정의한 셋
- Claude Code + GPT
- Codex + Claude 구독
- Claude Code + Cursor 구독

⚠️ **OpenRouter·DeepSeek 경유는 이 범위가 아니다.** 그건 API 키 라우팅이고 1-12-2 의 교차 라우팅
정의에 없다. **잠그지 않는다.**

### 구현 시 확인할 것
- **기존에 교차 조합으로 만들어진 멤버가 있는가.** 있으면 그것까지 끊을지 별도 판단이 필요하다
  (새 선택만 막고 기존은 두는 것이 안전하다)
- 잠긴 이유를 화면에서 **말해야 한다** — 조용히 목록에서 사라지면 "왜 없지"가 된다
- 기능정의서 1-12-2 에 **잠금 사실 명시**

## ⚠️ 고치는 것보다 "베타 범위에 넣을지"가 먼저다

- 교차 라우팅은 **가장 깨지기 쉬운 표면**이다. **양쪽 하네스의 변경에 동시에 노출된다** —
  Claude Code 가 바뀌어도 깨지고, Cursor 가 바뀌어도 깨진다.
- 그런데 이 앱의 정체성은 **여러 멤버가 함께 도는 것**이지 교차 라우팅이 아니다.

**선택지:**

| | 내용 | 비용 |
|---|---|---|
| **ⓐ** | 고쳐서 낸다 | 높다. 조합마다 무한히 잡게 될 위험 |
| **ⓑ** | **실험 기능으로 표시**하고 낸다 | 낮다. 기대치를 낮추고 제보를 받는다 |
| **ⓒ** | 베타에서 뺀다 | 가장 낮다. 다만 차별점 하나를 감춘다 |

**셋 중 하나를 정하고 나서 버그를 잡는 것이 순서다.**
안 그러면 조합마다 무한히 잡게 된다.

**권장: ⓑ.** 교차 라우팅은 이 앱만 가진 것이라 감추면 아깝고,
그렇다고 베타에서 완벽하게 만들 수도 없다. **"실험 기능"이라고 말하면 둘 다 피한다.**
단 ⓑ 를 택하면 **실험 기능임을 화면에서 알려야** 하고, 그건 만들 것이 있다는 뜻이다.
