# F-01. 폰트 설정

**판정: 미정** · 출처: 사용자

## 무엇을

사용자가 폰트를 설정할 수 있게 한다.

## 지금은

- 대화 영역에 **`Ctrl+마우스 휠` 글자 배율**만 있다 (기능정의서 5-1-2).
  저장·복원되고, 브라우저 확대와 분리돼 대화 텍스트에만 적용된다.
- **설정 화면에 폰트 항목이 없다** — 배율을 숫자로 지정하거나 되돌릴 방법이 없다.
- **폰트 종류(패밀리) 선택은 아예 없다.**

## 왜

코딩 에이전트를 종일 들여다보는 앱이다. **글자는 이 앱에서 사용자가 가장 오래 보는 것**이고,
읽기 편한 정도는 사람마다 다르다. 지금은 우연히 발견해야 하는 숨은 조작(`Ctrl+휠`) 하나뿐이다.

## 정해야 할 것

- **크기만인가, 패밀리까지인가** — 크기만이면 훨씬 싸다.
- **대화창만인가, 앱 전체인가** — 지금 배율은 대화 텍스트에만 걸린다.
  사이드바·설정 화면이 그대로면 어색할 수 있다.
- **코드 블록용 고정폭 폰트를 따로 둘 것인가** — 코드가 많이 나오는 앱이라 값이 있다.
- 기존 `Ctrl+휠` 배율과 **어떻게 합칠 것인가.** 두 개의 크기 개념이 생기면 안 된다.

## 재료

색은 `src/renderer/theme/themes.ts` 가 단일 소스다. **폰트도 같은 자리에 두는 것이 맞다** —
따로 두면 테마와 어긋난다.
