# B-08. 통계가 제대로 산출되지 않는다

**판정: 차단 유력** · 갈래: *숫자가 안 맞는다* + *있는데 못 쓴다* · 출처: 사용자

## 무엇을

통계 화면의 수치가 제대로 나오지 않는 것이 있다.

## 🔴 조사에서 성격이 바뀌었다 — "미완"이 아니라 "문서가 안 따라온 것"

처음엔 기능정의서가 통계를 **`🚧 개발 중`** 으로 적어 둔 것을 보고
*"미완인 채로 화면에 있다"* 고 판단했다. **정정한다.**

실제로는 **1187줄짜리 `src/renderer/usage/TokenUsageView.tsx` 가 붙어서 화면에 나와 있다.**

> 즉 **만들어 놨는데 문서가 안 따라온 것**이다.

**그래서 선택지가 달라진다:**
- ❌ ~~"감추기"~~ — 만들어 놓은 것을 감추는 건 낭비다
- ⭕ **"고치고 문서를 맞추기"**

⚠️ **문서와 코드가 어긋난 자리가 여기만이 아니다.** Guardian 도 같은 상태다
([B-13](B-13%20권한%20승인%20UI%20QA.md)). 이번 기회에 **기능정의서 2장을 실제 화면 기준으로 채울 것.**

## ⚠️ B-04 와 한 작업이다

**같은 데이터(`turns.jsonl`)를 먹는다.** 따로 고치지 말 것 —
[B-04](B-04%20사용량%20산출.md) 를 고치면 여기 절반이 같이 해결될 가능성이 높다.

## 알려진 함정 — 재작업 시 반드시 볼 것

두 가지를 혼동하면 숫자가 틀린다:

1. **게이트 리뷰 턴은 리뷰어 모델로 기록된다** → 멤버 모델 집계에서 **빼야 한다**
   (`isMemberModelTurn`).
2. **`tokens.context` 는 누적 합이 아니라 점유량이다** — 더하면 안 된다.

## 정해야 할 것

- **어디가 틀리는지 특정** — 사용자 보고가 *"제대로 산출이 안 된다"* 수준이라 좁혀야 한다.
  안 뜨는가 / 0 인가 / 갱신이 멈추는가 / 값 자체가 틀리는가.
- **통계가 무엇을 답해야 하는가** — 지금 화면이 답하려는 질문이 무엇인지 먼저 정하면
  어떤 수치가 틀렸는지도 분명해진다.
