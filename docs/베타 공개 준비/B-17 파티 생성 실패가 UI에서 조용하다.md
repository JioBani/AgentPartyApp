## ✅ 완료 — 파티 생성 하나가 아니라 **같은 모양 19곳**을 잡았다

### 근본 원인 (한 줄)
> 이 화면의 변경 동작 대부분이 JSX 에서 **`void f()` 로 던져지고 아무도 안 받는다.**

그래서 실패가 **unhandled rejection** 이 되고 — [B-14](B-14%20크래시%20처리%20부재.md) 덕분에
**로그에는 남지만** 클릭한 사람에게는 **아무 일도 안 일어난 것처럼** 보였다.

파티 생성이 최악이었던 이유: **입력창이 성공했을 때와 똑같이 비워진다.**
그래서 *"만들어졌다"* 로 읽히고, 목록엔 없으니 사용자는 **자기가 뭘 잘못했는지** 찾게 된다.

### 훑은 결과 — 받는 사람이 없는 변경 동작 **19개**
전부 같은 모양이었다:
파티 생성·전환·삭제 · 멤버 생성·삭제·닫기·재시작 · **승인 전달** ·
중단/강제종료/재시작 · 압축 · auto-compact · Message Gate(멤버/파티) ·
추론 강도/모드 · Codex 모델 새로고침

⚠️ **`승인 전달(approve)` 이 [B-05](B-05%20권한%20막힘%20침묵.md) 와 직접 닿는다** —
승인이 전달 안 되면 **멤버는 영원히 기다리는데 화면은 조용했다.**
B-05 가 보고된 증상의 **일부가 여기서 나왔을 수 있다.**

### 표면은 새로 만들지 않았다
앱에 이미 `setPartyNotice()` 토스트가 있고 **이미 10곳에서 오류 표시에 쓰고 있었다.**
거기에 잇는 헬퍼 하나만 추가:

```ts
const noticeOnFailure = useCallback(
  (what: string) => (error: unknown) =>
    setPartyNotice(`${what}: ${ipcErrorMessage(error)}`), []);
```

`what` 은 **사용자의 동작**이지 IPC 채널명이 아니다 — *"파티를 만들지 못했습니다"*.

### 조사 문서 지적은 절반만 맞았다
`App.tsx:1067~` 세션 시작은 **이미 `setPartyNotice` 로 보고하고 있었다**(사유별 1회 가드까지).
문제는 **`.then()` 만 있고 `.catch()` 가 없어서 `ensureSession` 자체가 reject 하면 사라진** 것.
그 구멍만 막았다.

## 증상 (실측 확인)

쓰기 불가한 작업공간(`C:\Windows\System32`)에서 파티를 만들면:

| 경로 | 동작 |
|---|---|
| **HTTP API** `POST /api/parties` | ✅ 오류를 정직하게 반환 — `{"error":"EPERM: operation not permitted, mkdir 'C:\\Windows\\System32\\.agent_party_app\\...'"}` |
| **로그** | ✅ 남는다 — `ipc: party:createParty failed` |
| **실제 UI** | 🔴 **파티 이름 입력 → Enter → 입력창이 비워지고 끝.** `PARTIES 0`, 화면 어디에도 오류 없음 |

캡처: `shots/b15-ui-create-fail.png`

## 왜 차단인가

> **입력창이 비워지는 것은 "성공했다"는 신호다.** 사용자는 파티가 만들어졌다고 믿는다.

그리고 목록에는 안 보이니 **자기가 뭘 잘못했는지 찾다가 포기한다.**
새 사용자가 **처음 하는 동작**이 파티 생성이므로([조사-첫 실행 경험](조사-첫%20실행%20경험.md)),
여기서 조용히 실패하면 **앱을 다시 안 켠다.**

## ⚠️ "기록은 되는데 사용자만 모르는" 침묵이다

AGENTS.md 정면 위반이다:
> *"실패를 조용한 폴백으로 감추지 마라. 로그·알림 등 눈에 보이는 진단으로 드러내라."*

**로그에는 남고 API 는 정직한데 화면만 침묵한다** — 즉 **진단 자체는 이미 있고,
그것을 화면까지 잇는 마지막 한 칸이 비어 있다.** 그래서 고치는 비용이 낮다.

## 범위 — 이건 결정 항목이 아니다

무엇을 보여줄지 정하는 문제가 아니라 **이미 있는 오류를 화면에 잇는 문제**다.
앱에는 이미 `setPartyNotice()` 같은 알림 표면이 있다.

⚠️ **다만 파티 생성 하나만 고치면 안 된다.** 같은 모양(IPC 실패가 UI 에서 삼켜짐)이
다른 동작에도 있는지 **함께 훑을 것.** 한 군데만 고치면 옆에서 또 나온다.
