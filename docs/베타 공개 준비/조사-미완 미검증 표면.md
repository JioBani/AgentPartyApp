보고된 7건 중 4건(통계 개발 중 · Gate fail-open · 모델 조회 실패 시 대체 없음 ·

## ① 파티가 0개일 때 갈 곳이 없다

새 사용자가 **처음 보는 화면**이다.

- `src/renderer/workbench/PartySidebar.tsx:269` — `No members`
- `src/renderer/workbench/Workbench.tsx:613-617` — *"왼쪽에서 멤버를 클릭해 패널로 열어 시작하세요"*

**그런데 파티가 없으면 클릭할 멤버도 없다.**
**"먼저 파티를 만들라"는 안내가 어디에도 없고**, 멤버 추가 `+` 를 눌러도 활성 파티가 없어
뜻대로 동작하지 않는다.

→ [F-10](F-10%20앱%20도우미%20세션.md) · [B-15](B-15%20기본%20작업공간.md) ·
[조사-첫 실행 경험](조사-첫%20실행%20경험.md) 과 **같은 자리**다. 합쳐서 처리한다.

## ② 통계는 문서와 코드가 어긋나 있다

기능정의서는 통계를 `🚧 개발 중` 이라 적었는데,
실제로는 **1187줄짜리 `TokenUsageView.tsx` 가 붙어서 화면에 나와 있다.**

→ [B-08](B-08%20통계%20산출.md) 의 성격이 분명해졌다: *"미완이라 안 만든 것"* 이 아니라
**"만들어 놨는데 문서가 안 따라온 것"**. 선택지는 "감추기"보다 **"고치고 문서를 맞추기"** 다.

## ⚠️ 이 조사가 B-05 를 찾지 못했다 — 그게 결론이 아니다

조사는 *"권한 막힘 시 조용한 실패는 발견되지 않았다. 코드가 침묵을 명시적으로 거부한다"* 고
보고했다. **하지만 사용자는 실제로 겪었다.**

> 코드를 읽어 못 찾았다는 것은 **없다는 뜻이 아니라, 코드 읽기로는 안 잡힌다는 뜻**이다.

같은 함정이 [#21] 에서 이미 있었다 — 검증 수단이 실제 죽음을 만들지 못해 결함이 드러나지
않았고, *"테스트가 관찰한 게 아니라 답을 알려준"* 경우였다.

→ **[B-05](B-05%20권한%20막힘%20침묵.md) 는 코드 검색이 아니라 실제 재현으로 접근할 것.**

## 이 조사에서 배운 것 (방법론)

**"무엇이 미완인가"를 코드에서 찾는 접근은 회수율이 낮았다.**
이 저장소는 제약을 문서에 성실히 적어 두는 편이라, 코드 검색이 찾아내는 것의 상당수가
**이미 알려진 것**이다.

→ 남은 미발견 결함은 **실제 사용(재현)으로만 나온다.** 사용자 보고가 코드 조사보다
정보량이 많았던 이번 경험이 그 증거다.
