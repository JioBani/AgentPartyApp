# 조사 — 개인화 하드코딩

*"지금은 나한테 너무 맞춰져 있다"* 를 코드 수준에서 확인한 결과.

---

## ✅ 결론부터 — 코드는 깨끗하다

**`src/` 에서 개인 정보·개인 경로가 발견되지 않았다.**

| 확인 항목 | 결과 |
|---|---|
| 하드코딩된 절대 경로 (`C:\Users\Dev\…` 등) | **없음** |
| 개인 이메일·계정명·머신명 | **없음** |
| Discord 길드/채널 ID | **없음** (전부 런타임 사용자 설정) |
| 작성자의 다른 프로젝트 참조 (Tatica·Canopy 등) | **`src/` 에 없음** (디자인 핸드오프 문서의 예시 데이터에만 존재 — 배포 안 됨) |
| 작성자 전용 기본값 (모델·멤버 이름·파티 규칙) | **없음** — 전부 일반적 |
| 코드에 박힌 비밀값 | **없음** (환경변수 또는 런타임 `settings.json` 경유) |

**→ 이 항목은 베타 차단이 아니다.**

## ⚠️ 그래서 "나한테 맞춰져 있다"의 정체가 분명해졌다

**개인 데이터가 박혀 있는 문제가 아니다.** 실제 과적합은 **행동과 검증 범위**에 있다:

- 작성자가 **안 쓰는 화면이 검증되지 않았다** → [B-13](B-13%20권한%20승인%20UI%20QA.md)(승인 모드)
- 작성자가 **항상 같은 폴더에서 열어서 안 겪는 문제** → [B-11](B-11%20파티%20찾기.md)(파티 찾기)
- 작성자는 **다 알고 있어서 필요 없던 것** → [F-09](F-09%20도움말.md)/[F-10](F-10%20앱%20도우미%20세션.md)(도움말)
- 작성자만 읽을 수 있는 말이 화면에 있다 → [D-02](D-02%20내부%20용어%20노출.md)(`spawn` 등)

**즉 고칠 대상은 코드에 박힌 문자열이 아니라 "안 밟아본 경로"다.** 이 조사의 가장 값진 결과다.

## 정리하면 좋은 것 (배포 차단 아님)

### `.mcp.json` — 저장소에만 있는 개인 경로
`.mcp.json:6` 에 `c:\Users\Dev\.vscode\extensions\agentparty.agentparty-vscode-0.0.1\...` 가 박혀 있다.
**패키지에는 실리지 않는다**(빌드 포함 목록 밖). 다만 **git 에 추적 중**이라
**저장소를 공개할 때는 차단 요소가 된다.**

→ 지금은 **정리 항목**. 저장소 공개 결정이 서면 그때 `git rm --cached` + `.gitignore`.

### `.env` — ✅ 유출 없음 확인
실제 키 3개(OpenRouter·Discord 봇 토큰·DeepSeek)가 들어 있다.
`.gitignore:6` 에 있고, **`git log --all -- .env` 결과 커밋 이력 0건** — 한 번도 올라간 적 없다.
그대로 두면 된다.

### `.gitignore` 의 `새 폴더/`
개인 작업 흔적. 저장소 공개 시 정리.

## 언어 — 한국어·영어 혼재, i18n 계층 없음

- 사용자에게 보이는 문자열의 **대략 20~30% 가 한국어**, 나머지는 영어.
- **i18n 미들웨어가 없다.** 문자열이 코드에 직접 박혀 있다.
  - `src/renderer/app/secondaryViews.tsx:268` — `"새 OpenRouter API 키 입력 (sk-or-…)"`
  - `src/renderer/workbench/MemberWizard.tsx:17` — `"새 멤버가 첫 작업부터 사용할 Claude Code 권한 모드입니다."`
  - `src/shared/discordBridge.ts:54` — 채널 주제에 `파티 '${…}'`

### 판단 — **베타에서 i18n 은 하지 않는다**
- 전 문자열 리팩터링이 필요해 **비용이 이 문서의 다른 어떤 항목보다 크다.**
- **배포 대상이 누구인지 먼저 정해야 한다.** 한국어 사용자 대상 베타라면 지금이 문제가 아니다.
- **⚠️ 다만 지금은 한국어와 영어가 섞여 있어서, 어느 쪽 사용자에게도 일관되지 않다.**
  i18n 을 넣지 않더라도 **한쪽으로 통일하는 것**은 훨씬 싸고 효과가 있다.
  → [D-02](D-02%20내부%20용어%20노출.md)(용어표)와 **같이 하면 한 번에 끝난다.**
