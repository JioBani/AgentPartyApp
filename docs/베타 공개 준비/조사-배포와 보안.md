## 판단 필요

### 자동화 HTTP API 에 인증이 하나도 없다
루프백 바인딩이 **유일한 보호막**이다. 로컬 프로세스면 무엇이든
**멤버 생성 · 메시지 전송 · 권한 변경 · 기록 열람**이 가능하다.
CORS 는 `http://127.0.0.1` 로 고정돼 있으나 이는 방어의 보조일 뿐이다.

- **로컬 전용인 동안은 감수 가능**하다(이 앱이 이미 로컬 CLI 를 권한 갖고 돌리는 물건이다).
- ⚠️ **원격 사용(아이디어 D-1)으로 가는 순간 즉시 차단 요소**가 된다.
  기획 노트 §8.6.2 가 이미 *"이걸 그대로 외부에 노출하는 것이 첫 번째 금지 사항"* 이라고 적어 뒀다.

**→ 베타에서는 그대로 두되, 원격 작업을 시작하는 시점에 인증을 선행 조건으로 못 박는다.**

### API 키가 `settings.json` 에 평문
OpenRouter · DeepSeek 키, Discord 봇 토큰이 사용자 데이터 폴더에 평문으로 저장된다.
(Codex 인증 저장소는 `0o600` 으로 원자적 저장 — 이쪽은 잘 돼 있다.)

같은 PC 를 여러 사람이 쓰면 노출될 수 있다.
**→ 최소한 경계를 문서에 명시.** OS 자격증명 저장소로 옮기는 것은 베타 후 검토.

## 안전 ✅

| 항목 | 상태 |
|---|---|
| QA 표면 (`/api/qa/*`) | `AGENTPARTY_QA=1` 없으면 거부. 패키지 빌드에서 안전 |
| DevTools | 개발 모드(`AGENTPARTY_RENDERER_URL`)에서만 열림 |
| Electron 하드닝 | `contextIsolation: true`, `nodeIntegration: false`, preload 게이트웨이 |
| 외부 링크 | `shell.openExternal()` 이 `https?://` 만 통과 |
| 소스맵 | 프로덕션 빌드에 미포함 |
| 신규 멤버 기본 권한 | `default` — 위험한 기본값 아님 |
| 빌드 타깃 | Windows(`nsis`·`portable`) — **플랫폼 확정과 이미 일치** |

⚠️ `sandbox: false` — 사유가 주석에 있고 `contextIsolation` + preload 로 완화돼 있다.
**베타에서 바꾸지 말 것**(Windows 경로 호환 때문). 다만 **왜 껐는지 문서에 남길 것.**
