# 지원되지 않거나 제공되지 않는 기능

지원되지 않는 기능을 확인하느라 불필요한 시간이 소요되지 않도록 현재 제공 범위를 안내한다.

## 현재 제한된 기능

- **교차 하네스 조합 3종** — Claude Code + GPT, Codex + Claude 구독,
  Claude Code + Cursor 구독 조합은 베타 기간에 선택할 수 없다. 모델 목록에 `베타 잠금` 배지와 제한 사유가 표시된다.
  OpenRouter·DeepSeek 모델을 Claude Code / Codex에서 실행하는 것은 잠금 대상이 **아니다** → `party.md`
- **Codex의 MCP 서버 켜기/끄기** — 설정 파일을 통해 관리되므로 실행 중 토글 기능을 제공하지 않는다.

## 현재 진입점이 제공되지 않는 기능

- **Cursor 로그인/로그아웃** — 앱에서 제공하지 않는다. 로컬 Cursor CLI의 로그인 상태를 사용한다 → `connect.md`
- **OpenRouter 키 삭제** — HTTP API 에만 있고 인증 화면에는 버튼이 없다.
- 기타 API·에이전트 도구에서만 제공되는 기능 — Claude 구독 해제, 기존 세션 바인딩,
  전체 상태 조회, 일괄 중단, 전체 방송, Message Gate 1회 우회.

## 혼동하기 쉬운 기능

- **멘션은 메시지를 전송하지 않는다.** `@이름`은 표시용 문자열이며, 해당 멤버에게 메시지를 자동으로 보내지 않는다 → `talk.md`
- **탭을 닫으면 세션이 종료된다.** 화면에서 탭만 제거되는 것이 아니다 → `screens.md`
- **강제 종료는 하네스 프로세스를 종료하지 않는다.** 현재 턴만 중단한다 → `talk.md`
- **전역 기본값은 기존 멤버의 설정을 변경하지 않는다.** 에이전트 화면의 값은 이후 생성되는 멤버에 적용된다.
- **전송 시 인터럽트 기본값은 입력창에만 적용된다.** HTTP API로 메시지를 보낼 때는 호출별로 직접 지정한다.
- **첨부 파일 제한은 모델마다 다르다.** 한 모델에서 허용된 첨부 개수가 다른 모델에서는 제한될 수 있다.
- **대기열은 최대 20건이다.** 한도를 초과하면 메시지 추가가 거부된다.
- **Discord 허용 사용자 목록이 비어 있으면 모든 사용자의 메시지 전송이 차단된다.** 빈 목록은 전체 허용을 의미하지 않는다.

## 개발 중인 기능

- **글자 크기** 조절은 글꼴 선택 기능이 아니다. 대화 영역에서 `Ctrl + 마우스 휠`을 사용하여 조절한다.

## 가이드에서 답변하지 않는 내용

- **현재 앱에서 발생한 문제** — 멤버 중단 사유, 로그인 실패 사유,
  현재 파티의 멤버 구성 등. 이 문서는 앱의 현재 상태를 직접 조회할 수 없다.
  왼쪽 메뉴의 **문제 해결**에서 현재 상태를 조회하고 진단할 수 있다.
- **사용자 프로젝트 코드 작성·수정** — 파티 멤버에게 요청해야 하는 작업이다.
