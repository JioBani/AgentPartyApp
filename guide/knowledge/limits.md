# 안 되는 것, 아직 없는 것

"왜 안 되지?" 로 시간을 버리지 않도록, 없는 것을 없다고 적어 둔다.

## 지금은 막아 둔 것

- **교차 하네스 조합 3종** — Claude Code + GPT, Codex + Claude 구독,
  Claude Code + Cursor 구독. 베타 기간 동안 선택할 수 없고, 모델 목록에 `베타 잠금` 배지와 이유가 표시된다.
  OpenRouter·DeepSeek 모델을 Claude Code / Codex 에서 돌리는 것은 잠금 대상이 **아니다** → `party.md`
- **Codex 의 MCP 서버 켜기/끄기** — 설정 파일 기반이라 실행 중 토글을 제공하지 않는다.

## 애초에 진입점이 없는 것

- **Cursor 로그인/로그아웃** — 앱 안에 없다. 로컬 Cursor CLI 의 로그인 상태를 그대로 쓴다 → `connect.md`
- **OpenRouter 키 삭제** — HTTP API 에만 있고 인증 화면에는 버튼이 없다.
- 그 밖에 API·에이전트 도구로만 되는 것들 — Claude 구독 해제, 기존 세션 바인딩,
  전체 상태 조회, 일괄 중단, 전체 방송, Message Gate 1회 우회.

## 헷갈리기 쉬운 것

- **멘션은 전송이 아니다.** `@이름` 은 글자일 뿐, 그 멤버에게 메시지를 보내지 않는다 → `talk.md`
- **탭 닫기는 세션 종료다.** 화면만 치우는 게 아니다 → `screens.md`
- **강제 종료가 프로세스를 죽이지는 않는다.** 그 턴만 끊는다 → `talk.md`
- **전역 기본값은 이미 만든 멤버를 덮어쓰지 않는다.** 런타임 화면의 값은 *앞으로 만들* 멤버용이다.
- **전송 시 인터럽트 기본값은 입력창에만 적용된다.** HTTP API 로 보낼 때는 호출마다 직접 지정한다.
- **첨부 상한은 모델마다 다르다.** 한 모델에서 되던 개수가 다른 모델에서 거절될 수 있다.
- **대기열은 20건까지.** 넘으면 거부한다.
- **Discord 허용 사용자 목록이 비면 아무도 못 보낸다.** 빈 목록은 전체 허용이 아니다.

## 아직 만드는 중

- **Token Usage** 화면 — 구성이 바뀔 수 있다.
- **글자 크기**는 글꼴 선택 기능이 아니다. 대화 영역에서 `Ctrl + 마우스 휠` 로 조절한다.

## 이 가이드가 답하지 않는 것

- **지금 내 앱에서 벌어지는 일** — 내 멤버가 왜 멈췄는지, 내 로그인이 왜 안 되는지,
  지금 파티에 누가 있는지. 이 문서는 앱을 들여다볼 수 없다.
  왼쪽 메뉴의 **문제 해결**이 실제로 조회하고 진단한다.
- **사용자 프로젝트 코드 작성·수정** — 그건 파티 멤버에게 시킬 일이다.
