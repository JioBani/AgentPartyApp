# 멤버와 대화하기

멤버를 선택하면 대화창이 열린다. 입력창은 **멤버별로 분리되어 있어** 작성 중인 내용이 다른 멤버의 입력창과 섞이지 않는다.

## 메시지 전송

- 기본 전송 키는 `Ctrl/Cmd + Enter`다. **런타임** 화면에서 `Enter`로 변경할 수 있으며,
  `Enter`를 전송 키로 설정하면 `Shift + Enter`로 줄을 바꿀 수 있다.
- 전송 키 설정은 창 너비나 패널 크기와 관계없이 동일하게 적용된다.
- 빈 메시지는 보내지지 않는다.
- 세션이 시작되지 않은 멤버에게 메시지를 보내면 **세션이 자동으로 시작된다.**
- 입력창 높이는 내용에 따라 자동으로 조절되며, 최대 높이를 초과하면 입력창 내부에 스크롤이 표시된다.

## 첨부

클립보드 붙여넣기와 파일 드롭을 지원한다. 전송 전 미리보기에서 첨부 파일을 개별적으로 제거할 수 있다.

- 첨부 파일 개수 및 파일별 크기 제한은 **모델마다 다르다.**
- 이미지 입력을 지원하지 않는 모델에는 이미지를 첨부할 수 없다.
- 파일 읽기 실패·크기 초과·개수 초과 사유는 각각 표시된다.
- 이전 대화 기록을 복원할 때 원본 파일 대신 **파일명만** 표시될 수 있다.

## 응답 중단

응답 중에는 Send 버튼이 **Stop**으로 변경된다. Stop을 선택하면 현재 턴을 중단하고 멤버가 유휴 상태로 전환된다.
정상적으로 중단되지 않으면 강제 종료가 실행된다.

⚠ 강제 종료는 **하네스 프로세스 자체를 종료하지 않는다.** 현재 턴만 중단한다.

## 작업 중인 멤버의 메시지 대기열

멤버가 작업 중일 때 전송한 메시지는 앱에 저장되며, 멤버가 유휴 상태로 전환되면 **저장된 순서대로 전달된다.**

대기열에서 다음 작업을 수행할 수 있다.

- 대기 중인 메시지 수 및 내용 확인
- 개별 메시지 취소, 텍스트 편집 및 변경 내용 되돌리기
- 드래그하여 전송 순서 변경
- 동일한 발신자의 메시지를 드래그하여 **하나의 메시지로 병합**
- **지금 보내기** — 선택한 메시지를 대기열의 첫 번째 위치로 이동하고 멤버의 현재 턴을 Stop으로 중단한 후 즉시 전달
- 대기 메시지를 대화창으로 드래그하여 즉시 전달
- 모든 대기 메시지 취소(빨간색 버튼 및 두 단계 확인)

⚠ 발신자가 다른 메시지는 **병합할 수 없다.** 메시지별 발신자 정보를 유지하기 위한 제한이다.
⚠ 이미 하네스로 전달되어 취소할 수 없는 메시지 수는 취소 가능한 메시지 수와 **구분하여** 표시된다.
⚠ 대기열에는 최대 20건을 저장할 수 있다. 한도를 초과하면 메시지 추가가 거부된다.

대기열의 메시지는 앱을 재시작해도 유지된다.

## 다른 멤버 지칭하기 — 멘션

입력창에 `m:` `:m` `member:` `:member` 중 하나를 입력하면(대소문자 구분 없음) 멤버 목록 팝오버가 열린다.
멤버를 선택하면 `@이름` 칩이 입력된다. 멤버가 두 명 이상이면 `@everyone`도 표시된다.

⚠ 멤버 목록을 여는 키로 `@`를 사용하지 않는 이유는 하네스에서 이미 `@`를 사용하기 때문이다.
(Codex는 스킬·플러그인·파일 선택기, Claude Code는 파일 멘션에 사용한다.) 입력 결과는 `@이름` 형식이다.

⚠ 멘션은 **멤버 이름을 표시하는 기능이며 메시지를 전송하지 않는다.** 멘션을 입력해도 해당 멤버에게 메시지가 자동으로 전달되지 않는다.
메시지 전송 방법 → `collab.md`

## 명령 팔레트

입력 내용을 `/`로 시작하면 하네스에서 제공하는 명령 목록이 열린다.
명령은 Commands · Skills · Agents · MCP prompts · Plugins · AgentParty로 분류되며 이름이나 설명으로 검색할 수 있다.

명령 실행 전 설명·인자 형식·출처가 표시되며, 다음과 같은 배지로 명령 특성이 안내된다.
git 필요 · 읽기 전용 · **파일 수정** · 백그라운드 · 클라우드 · 인증 필요 · **파괴적**.

`compact` · `restart` · `interrupt` 등의 명령은 입력창에 추가되지 않고 즉시 실행된다.
(Cursor의 컨텍스트 압축 명령은 `/compress`다.)

## 대화 기록에 표시되는 항목

- 사용자가 보낸 메시지, 첨부 이미지 및 전송 시각
- AI 응답 — Markdown 형식으로 렌더링되며 표·코드 블록·목록·링크를 지원한다.
- **모델의 생각**은 접힌 별도 영역에 표시된다.
- **도구 실행** — 도구명, 실행 명령 원문, 작업 디렉터리, 종료 코드, 소요 시간, 출력
  결과에 이미지가 포함된 경우 이미지로 표시하며, 해당 결과 영역은 기본적으로 펼쳐진다.
- **계획과 변경** — 체크리스트, 변경된 파일 수, 추가·삭제된 줄 수, 파일별 diff
- **진단** — 사용자에게 명확히 안내해야 하는 모델 재라우팅·사용 한도·인증 변경·권한·MCP 등의 상태

대화 기록이 길어지면 최근 150개 항목을 먼저 표시하고, `이전 기록 보기`를 선택할 때마다 이전 항목을 150개씩 추가로 불러온다.
이전 기록을 불러온 후에도 현재 스크롤 위치가 유지된다. 화면이 맨 아래에 있을 때만 새 메시지로 자동 이동한다.

### 링크와 파일 경로

대화에 포함된 링크는 **항상 운영체제의 기본 앱으로 열린다.** AgentParty 앱 창은 링크 대상으로 전환되지 않는다.

- `http(s)`·`mailto:` → 기본 브라우저 또는 메일 앱
- 스킴이 없어도 호스트 형식으로 확인되면 `https`를 적용
- 로컬 파일 경로 → 해당 파일의 기본 앱. 기본 앱이 없으면 **파일 관리자에서 파일 위치만 표시**
- 상대 경로는 **현재 창의 작업공간**을 기준으로 해석

⚠ 실행 파일·스크립트(`.exe` `.bat` `.ps1` `.vbs` `.lnk` 등)는 **실행하지 않고 파일 위치만 표시한다.**
모델이 생성한 링크이므로, 앱에서 실행 여부를 대신 결정하지 않는다.
⚠ 존재하지 않는 파일을 선택하면 해석된 경로가 포함된 오류 메시지를 표시한다.
