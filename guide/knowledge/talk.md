# 멤버에게 말 걸기

멤버를 클릭하면 대화창이 열린다. 입력창은 **멤버마다 따로** 있어서, 쓰다 만 글이 섞이지 않는다.

## 보내기

- 기본 전송 키는 `Ctrl/Cmd + Enter`. **런타임** 화면에서 `Enter` 로 바꿀 수 있고,
  그렇게 하면 `Shift + Enter` 가 줄바꿈이 된다.
- 전송 키는 창 폭이나 패널 크기와 **무관하게 항상 같다.**
- 빈 메시지는 보내지지 않는다.
- 아직 시작 안 한 멤버에게 보내면 **세션이 자동으로 시작된다.**
- 입력창은 내용에 따라 늘어나고, 일정 높이를 넘으면 안에서 스크롤된다.

## 첨부

붙여넣기(클립보드)와 파일 드롭 둘 다 된다. 보내기 전에 미리보기가 뜨고 하나씩 뺄 수 있다.

- 개수 상한과 장당 크기 상한은 **모델마다 다르다.**
- 이미지를 못 받는 모델에는 첨부가 거절된다.
- 읽기 실패·크기 초과·개수 초과는 각각 사유가 표시된다.
- 지난 기록을 되살릴 때는 원본 파일 대신 **이름만** 남아 있을 수 있다.

## 하던 말 멈추기

응답 중에는 Send 버튼이 **Stop** 으로 바뀐다. 누르면 현재 턴을 멈추고 유휴로 돌아온다.
안 멈추면 강제 종료로 넘어간다.

⚠ 강제 종료도 **하네스 프로세스 자체를 죽이지는 않는다.** 그 턴만 끊는다.

## 바쁜 멤버에게 보낸 메시지 — 대기열

멤버가 일하는 중에 메시지를 보내면 앱이 **보관했다가 유휴가 되면 순서대로** 넣어 준다.

대기열에서 할 수 있는 것:

- 몇 건 밀려 있는지 보고, 펼쳐서 내용 확인
- 개별 취소, 텍스트 편집(되돌리기)
- 드래그로 순서 변경
- 같은 발신자끼리 드래그해서 **하나로 합치기**
- **지금 보내기** — 그 항목을 맨 앞으로 올리고 멤버를 Stop 시킨 뒤 즉시 전달
- 대화창으로 끌어다 놓으면 즉시 전달
- 모두 취소(빨간 버튼 + 2단 확인)

⚠ 발신자가 다른 메시지끼리는 **합칠 수 없다.** 누가 한 말인지가 섞이면 안 되기 때문이다.
⚠ 이미 하네스로 넘어가 취소가 불가능한 건수는 취소 가능한 건수와 **구분해서** 표시된다.
⚠ 대기열은 20건까지다. 넘으면 거부한다.

대기 내용은 앱을 껐다 켜도 남는다.

## 다른 멤버 가리키기 — 멘션

입력창에서 `m:` `:m` `member:` `:member` 중 아무거나 치면(대소문자 무관) 멤버 목록 팝오버가 열린다.
고르면 `@이름` 칩으로 들어간다. 멤버가 둘 이상이면 `@everyone` 도 나온다.

⚠ 여는 키가 `@` 가 **아닌** 이유: `@` 는 하네스가 이미 쓰고 있다
(Codex 는 스킬·플러그인·파일 선택기, Claude Code 는 파일 멘션). 삽입된 결과는 `@이름` 그대로다.

⚠ 멘션은 **글자를 표시하는 기능일 뿐이다.** 멘션했다고 그 멤버에게 메시지가 자동으로 가지 않는다.
실제로 보내려면 → `collab.md`

## 명령 팔레트

입력을 `/` 로 시작하면 하네스가 제공하는 명령 목록이 열린다.
Commands · Skills · Agents · MCP prompts · Plugins · AgentParty 로 묶여 있고, 이름·설명으로 검색된다.

실행 전에 설명·인자 형식·출처가 보이고, 배지로 성격을 알려준다 —
git 필요 · 읽기 전용 · **파일 수정** · 백그라운드 · 클라우드 · 인증 필요 · **파괴적**.

`compact` · `restart` · `interrupt` 같은 건 입력창에 넣지 않고 바로 실행된다.
(Cursor 의 압축 명령은 `/compress` 다.)

## 대화 기록에서 보게 되는 것

- 내가 보낸 글과 첨부 이미지, 보낸 시각
- AI 응답 — Markdown 으로 렌더된다. 표·코드 블록·목록·링크
- **모델의 생각**은 따로 접혀서 표시된다
- **도구 실행** — 도구 이름, 실행한 명령 원문, 작업 디렉터리, 종료 코드, 걸린 시간, 출력.
  결과에 이미지가 있으면 **그림으로** 보여주고, 그런 상자는 기본으로 펼쳐진다
- **계획과 변경** — 체크리스트, 바뀐 파일 수와 추가/삭제 줄 수, 파일별 diff
- **진단** — 조용히 넘기면 안 되는 일(모델 재라우팅·사용 한도·인증 변경·권한·MCP 등)

기록이 길어지면 최근 150개만 먼저 그리고, `이전 기록 보기` 로 150개씩 더 불러온다.
불러와도 읽던 자리가 유지되고, 맨 아래에 있을 때만 새 메시지를 자동으로 따라간다.

### 링크와 파일 경로

대화 안의 링크는 **언제나 OS 기본 앱으로 열린다.** 앱 창이 링크 대상으로 바뀌는 일은 없다.

- `http(s)`·`mailto:` → 기본 브라우저·메일 앱
- 스킴이 없어도 호스트처럼 보이면 `https` 로 보정
- 로컬 파일 경로 → 그 파일의 기본 앱. 기본 앱이 없으면 **파일 관리자에서 위치만** 표시
- 상대 경로는 **그 창의 작업공간** 기준으로 푼다

⚠ 실행 파일·스크립트(`.exe` `.bat` `.ps1` `.vbs` `.lnk` 등)는 **절대 실행하지 않고 위치만** 보여준다.
그 링크를 쓴 건 모델이고, 실행 여부는 앱이 대신 정할 일이 아니다.
⚠ 없는 파일을 클릭하면 아무 일도 안 일어나는 대신, 해결된 경로가 담긴 오류가 뜬다.
