# 돈이 어디서 나가나

이 앱 자체는 요금을 받지 않는다. 비용은 **연결한 AI 제공자에게** 나간다
(구독 요금, 또는 OpenRouter 같은 종량 API 키).

## 무엇이 모델을 쓰고, 무엇이 안 쓰나

| 동작 | 모델을 쓰나 |
|---|---|
| 멤버에게 메시지 보내기 | **쓴다** |
| 멤버끼리 메시지 주고받기 | **쓴다** — 받는 멤버가 그 턴을 돈다 |
| Message Gate 심사 | **쓴다** — 심사 모델이 따로 한 번 돈다 |
| 서브에이전트 | **쓴다** — 각자 자기 턴을 돈다 |
| 컨텍스트 압축 | **쓴다** — 요약을 모델이 만든다 |
| 가이드 **채팅**(지금 이 대화) | **쓴다** |
| 가이드 **프레젠테이션** | **안 쓴다** — 미리 만들어 둔 화면을 그대로 보여 준다 |
| 화면 이동·설정·배치 변경 | 안 쓴다 |

가이드 화면 위쪽의 표시가 **지금 이 화면이 비용을 쓰는지 아닌지**를 알려 준다.
금액이나 토큰 수는 거기 나오지 않는다 — **쓴다/안 쓴다** 두 가지만이다.

## 놓치기 쉬운 것

- **Message Gate 를 켜면 메시지 하나마다 심사 모델이 한 번 더 돈다.** 본문보다 짧지만 공짜는 아니다.
- **자동 압축**은 임계값을 넘을 때 스스로 실행된다. 사람이 누르지 않아도 그 턴은 나간다.
- **전체 방송**은 받는 멤버 수만큼 턴이 동시에 시작된다.
- 멤버를 **열어 두기만 하는 것**은 비용이 아니다. 도는 턴만 비용이다.

## 얼마나 썼는지 보기

왼쪽 메뉴 **Token Usage**. 어디서 얼마나 나갔는지 집계된다.
(이 화면은 아직 개발 중이라 구성이 바뀔 수 있다.)

제공자별 **사용 한도**(구독의 5시간·주간 한도 같은 것)는 제목 표시줄의 표시로 확인한다.
한도에 걸리면 대화 안에 진단으로도 뜬다.

## 비싸게 쓰지 않으려면

- 무거운 모델을 모든 멤버에 쓰지 않는다. 검토·심사처럼 짧은 일에는 가벼운 모델로 충분하다.
- Message Gate 리뷰어는 특히 가벼운 모델로 둔다. 규칙 위반만 판정하면 되는 일이다.
- 대화가 길어지면 압축한다. 매 턴 전체 맥락을 다시 보내는 비용이 줄어든다.
