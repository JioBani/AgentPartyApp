# 구독 및 API 사용량

AgentParty 앱이 채팅 건별 요금을 따로 청구하지는 않는다. AI가 턴을 실행하면 선택한 모델에 연결된 **구독 사용량 또는 API 사용량**을 사용한다.

- Claude·Codex·Cursor 구독 모델은 연결한 계정의 구독 사용량과 한도를 사용한다.
- OpenRouter 모델은 등록한 API 키의 종량제 사용량을 사용한다.
- B.AI 모델은 등록한 API 키의 크레딧을 사용한다.

## 사용량을 쓰는 동작

| 동작 | AI 사용량 |
|---|---|
| 멤버에게 메시지 보내기 | **사용** |
| 멤버 간 메시지 전송 | **사용** — 수신 멤버가 해당 턴을 실행한다. |
| Message Gate 심사 | **사용** — 심사 모델이 별도의 턴을 한 번 실행한다. |
| 서브에이전트 | **사용** — 각 서브에이전트가 별도의 턴을 실행한다. |
| 컨텍스트 압축 | **사용** — 모델이 대화 요약을 생성한다. |
| 가이드 채팅 | **사용** — 가이드에서 선택한 모델의 연결 계정을 사용한다. |
| 화면 이동·설정·배치 변경 | **미사용** |

가이드 화면은 별도의 금액이나 비용 배지를 표시하지 않는다. 질문 입력창 위의 안내는 가이드 채팅이 연결한 AI 구독 사용량을 쓴다는 뜻이다.

## 추가 사용량이 생기는 기능

- **Message Gate**를 켜면 멤버 간 메시지를 보낼 때 심사 모델이 별도의 턴을 실행한다.
- **자동 압축**은 임계값을 넘으면 사용자가 직접 실행하지 않아도 모델을 사용해 요약을 만든다.
- **전체 방송**은 메시지를 받는 멤버 수만큼 턴이 시작된다.
- 멤버 세션을 열어 둔 것만으로는 사용량을 쓰지 않는다. 모델이 실제로 턴을 실행할 때 사용량을 쓴다.

## 사용량 확인

Claude·Codex 등 제공자별 구독 한도와 사용 상태는 제목 표시줄의 사용량 표시에서 확인한다. 구독 한도에 도달하거나 제공자가 요청을 거부하면 해당 멤버의 대화에 진단 메시지가 표시된다.

OpenRouter와 B.AI의 잔여 크레딧 및 청구 내역은 각 제공자 계정에서 확인한다. AgentParty의 **통계** 화면에 보이는 환산 금액은 모델 카탈로그 단가를 이용한 참고값이며 제공자의 실제 청구서가 아니다.

## 사용량 줄이기

- 고성능 모델을 모든 멤버에 적용할 필요는 없다. 검토·심사처럼 단순한 작업에는 경량 모델을 선택할 수 있다.
- Message Gate 리뷰어에는 경량 모델을 권장한다. 지정된 규칙의 위반 여부만 판단하기 때문이다.
- 대화가 길어지면 컨텍스트를 압축해 다음 턴에 전달되는 대화 맥락의 크기를 줄인다. 압축 자체도 한 번의 모델 사용이 필요하다.
