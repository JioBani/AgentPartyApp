# 비용 발생 기준

AgentParty 앱 자체는 별도 요금을 부과하지 않는다. 비용은 **연결된 AI 제공자에서** 발생한다.
(구독 요금 또는 OpenRouter와 같은 종량제 API 요금).

## 모델 사용 여부

| 동작 | 모델 사용 여부 |
|---|---|
| 멤버에게 메시지 보내기 | **사용** |
| 멤버 간 메시지 전송 | **사용** — 수신 멤버가 해당 턴을 실행한다. |
| Message Gate 심사 | **사용** — 심사 모델이 별도의 턴을 한 번 실행한다. |
| 서브에이전트 | **사용** — 각 서브에이전트가 별도의 턴을 실행한다. |
| 컨텍스트 압축 | **사용** — 모델이 대화 요약을 생성한다. |
| 가이드 **채팅**(현재 대화) | **사용** |
| 가이드 **프레젠테이션** | **미사용** — 미리 생성된 화면을 표시한다. |
| 화면 이동·설정·배치 변경 | **미사용** |

가이드 화면 상단의 표시에서 **현재 화면의 모델 사용 여부**를 확인할 수 있다.
해당 표시에는 금액이나 토큰 수가 아닌 **사용/미사용** 여부만 나타난다.

## 추가 비용이 발생할 수 있는 기능

- **Message Gate를 켜면 메시지마다 심사 모델이 추가로 한 번 실행된다.** 심사 내용이 짧아도 모델 사용 비용이 발생한다.
- **자동 압축**은 임계값을 초과하면 자동으로 실행된다. 사용자가 직접 실행하지 않아도 모델 사용 비용이 발생한다.
- **전체 방송**은 받는 멤버 수만큼 턴이 동시에 시작된다.
- 멤버의 세션을 **열어 둔 상태만으로는** 비용이 발생하지 않는다. 모델이 턴을 실행할 때만 비용이 발생한다.

## 사용량 확인

제공자별 **사용 한도**(구독의 5시간·주간 한도 등)는 제목 표시줄에서 확인할 수 있다.
사용 한도에 도달하면 대화에도 진단 메시지가 표시된다.

## 비용 절감 방법

- 고성능 모델을 모든 멤버에 적용할 필요는 없다. 검토·심사 등 간단한 작업에는 경량 모델을 사용할 수 있다.
- Message Gate 리뷰어에는 경량 모델 사용을 권장한다. 지정된 규칙의 위반 여부만 판단하기 때문이다.
- 대화가 길어지면 컨텍스트를 압축한다. 매 턴 전송되는 전체 대화 맥락의 크기를 줄여 비용을 절감할 수 있다.
