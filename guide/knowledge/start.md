# 처음 시작하기

설치하고 처음 켰을 때, 일이 굴러가기까지의 최단 경로.

## 순서

1. **계정을 연결한다** — 왼쪽 메뉴 **인증**.
   AI 를 하나도 연결하지 않으면 멤버가 아무 말도 못 한다. → `connect.md`
2. **작업공간을 고른다** — 상단의 **작업공간** 버튼, 또는 File 메뉴.
   작업할 폴더다. 멤버들은 이 폴더 안에서 파일을 읽고 고친다.
3. **파티를 만든다** — 왼쪽 사이드바에서 이름을 넣고 `+`.
   만들면 `main` 멤버가 자동으로 하나 생긴다.
4. **멤버에게 말을 건다** — 사이드바에서 멤버를 클릭하면 대화창이 열린다. 아래 입력창에 쓰고 보낸다.
5. **필요해지면 멤버를 늘린다** — 멤버 목록의 `+`. → `party.md`

## 작업공간이 왜 먼저인가

작업공간은 단순히 "열어 둔 폴더"가 아니라 **파티가 사는 곳**이다.
파티·멤버·대화 기록이 그 폴더 안(`.agent_party_app`)에 저장되므로,
폴더를 옮기거나 백업하면 파티도 같이 따라간다.
다른 폴더로 바꾸면 그 폴더의 파티 목록으로 화면이 통째로 바뀐다.

WSL 안의 폴더도 작업공간으로 쓸 수 있다(`wsl+<배포판>:/경로`, `\\wsl$\`, `\\wsl.localhost\`).
그 경우 배포판 이름이 배지로 표시된다.

경로를 해석하지 못하면 앱은 **비슷한 다른 폴더로 대신 열지 않고 경고를 띄운다.**
엉뚱한 폴더에서 작업이 시작되는 편이 훨씬 나쁘기 때문이다.

## 처음 설치했을 때 한 번 뜨는 것

최초 설치라면 "가이드를 먼저 보시겠습니까?" 팝업이 한 번 뜬다.
업데이트로 판단되면 뜨지 않는다. 끝까지 봤는지는 기록하지 않으므로,
가이드는 언제 다시 열어도 처음부터다.

## 화면 이동 단축키

- `Ctrl/Cmd + 1~5` — 화면 이동
- `Ctrl/Cmd + N` — 새 파티
- `Ctrl/Cmd + Shift + N` — 새 창
- `F1` — 이 가이드
