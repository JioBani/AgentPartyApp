# 처음 시작하기

설치 후 처음 실행할 때 작업을 시작하기 위한 기본 절차다.

## 순서

1. **계정을 연결한다** — 왼쪽 메뉴 **인증**.
   연결된 AI 제공자가 없으면 멤버가 응답을 생성할 수 없다 → `connect.md`
2. **작업공간을 선택한다** — 상단의 **작업공간** 버튼 또는 File 메뉴.
   멤버가 파일을 읽고 수정할 작업 폴더다.
3. **파티를 생성한다** — 왼쪽 사이드바에 이름을 입력하고 `+`를 선택한다.
   파티를 생성하면 `main` 멤버가 자동으로 생성된다.
4. **멤버에게 메시지를 보낸다** — 사이드바에서 멤버를 선택하여 대화창을 열고 하단 입력창에서 메시지를 작성해 전송한다.
5. **필요한 경우 멤버를 추가한다** — 멤버 목록의 `+`를 선택한다 → `party.md`

## 작업공간을 먼저 선택하는 이유

작업공간은 멤버가 기본적으로 파일을 읽고 수정할 프로젝트 폴더다.
파티·멤버·대화 기록은 Windows의 AgentParty 전역 저장소에서 관리되므로 작업공간을 바꿔도 같은 파티 목록을 사용할 수 있다.
멤버를 만들 때는 파티의 작업공간과 별도로 Windows·WSL·SSH의 실행 위치와 작업 폴더를 지정할 수 있다.

WSL 내부의 폴더도 작업공간으로 사용할 수 있다(`wsl+<배포판>:/경로`, `\\wsl$\`, `\\wsl.localhost\`).
WSL 작업공간에는 배포판 이름이 배지로 표시된다.

작업공간 경로를 해석할 수 없으면 앱은 **유사한 다른 폴더를 열지 않고 경고를 표시한다.**
의도하지 않은 폴더에서 작업이 시작되는 것을 방지하기 위한 방식이다.

## 가이드 열기

앱을 시작할 때 가이드 팝업은 자동으로 표시되지 않는다.
사용자가 좌측 레일의 `가이드` 버튼을 누르거나 `F1`을 누르면 언제든지 직접 열 수 있다.
현재 가이드는 질문을 입력하여 사용 방법을 확인하는 채팅만 제공하며, 슬라이드 프레젠테이션은 잠시 표시하지 않는다.

## 화면 이동 단축키

- `Ctrl/Cmd + 1~5` — 화면 이동
- `Ctrl/Cmd + N` — 새 파티
- `Ctrl/Cmd + Shift + N` — 새 창
- `F1` — 이 가이드
