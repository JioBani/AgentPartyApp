# AI 작업 권한과 안전 관리

AI가 작업공간의 파일을 다루는 앱이므로, 사용자가 멤버별 자율 실행 범위를 설정한다.

## 권한 — 멤버 시작 시 적용되는 수준

권한 체계는 **모델이 아닌 하네스**를 기준으로 적용된다. GPT 모델을 Claude Code에서 실행하면 Claude Code의 권한 체계를 사용한다.

**Claude Code 계열** — 다음 중 하나를 선택한다.
Default · Accept edits · Plan · Auto · Don't ask · Bypass permissions

**Codex 계열** — 다음 두 항목을 각각 설정한다.
- 샌드박스: `read-only` · `workspace-write` · `danger-full-access`
- 승인 정책: `untrusted` · `on-request` · `never`
- 조합 프리셋: Read Only · Auto · Full Access · Custom
- Guardian 사용 여부

권한은 대화 중에도 변경할 수 있으며 **다음 턴부터** 적용된다.
권한은 멤버별로 저장되므로 멤버를 닫거나 앱을 종료한 후 다시 열어도 유지된다.

## 승인 카드

AI가 현재 권한으로 허용되지 않은 작업을 요청하면 대화에 **승인 카드**가 표시되고, 사용자가 처리할 때까지 해당 멤버의 작업이 중단된다.

승인 카드에는 도구 이름과 설명, 실행할 명령 원문, 작업 디렉터리, 파일 diff, 요청 사유가 표시된다.
Codex는 "앞으로 항상 허용할 규칙"도 함께 표시한다.

선택 가능한 항목은 거부 · 이번 한 번 허용이다.
Codex는 승인 범위를 세분화하여 제공한다 — 이번 한 번 · 현재 세션 · **동일한 command prefix를 앞으로 항상 허용** · 거부.

승인 대기 중인 멤버는 사이드바에 배지로 표시된다. 요청을 처리한 후에도 승인 카드에 선택한 결과가 기록된다.

## 모델의 확인 질문

AI가 사용자 확인이 필요한 경우 선택지 카드가 표시된다.
단일·다중 선택, 선택지 설명, 기타/직접 입력, 자유 입력, 비밀 입력을 지원한다.
질문이 여러 개인 경우 이전/다음/건너뛰기를 사용할 수 있으며, 필수 항목을 입력하지 않으면 전송할 수 없다.

## 되돌릴 수 없는 작업

- **파티 삭제** — 멤버·메시지·역할 파일·디스크 저장소가 모두 삭제된다. 두 단계의 확인 절차를 거친다.
- **대기열 모두 취소** — 빨간색 버튼을 사용하며 두 단계의 확인 절차를 거친다.
- **계정 연결 끊기** — 두 단계의 확인 절차를 거친다. 자격 증명은 복구 가능한 백업 위치로 이동된다.

다음 기능은 되돌릴 수 있는 작업이다. **탭 닫기**는 실행만 중단하며 멤버와 기록은 유지된다 → `party.md`

## 앱에서 차단하는 작업

- 대화의 링크가 **실행 파일 또는 스크립트**인 경우 실행하지 않고 파일 위치만 표시한다 → `talk.md`
- 모델 목록 조회에 실패하면 **다른 제공자의 모델로 대체하지 않는다.**
- 인증 정보가 없거나 플랜에서 지원하지 않으면 **다른 모델로 자동 변경하지 않고** 오류를 표시한다.
- 작업공간 경로를 해석할 수 없으면 **유사한 다른 폴더를 대신 열지 않는다.**

공통 원칙은 **자동 대체를 수행하지 않고 오류를 명확하게 표시하는 것**이다.
의도하지 않은 모델로 작업이 장시간 진행되는 것을 방지하기 위한 방식이다.
