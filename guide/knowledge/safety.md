# 멋대로 못 하게 막는 것들

AI 에게 폴더를 통째로 맡기는 앱이다. 그래서 "무엇까지 스스로 해도 되는가"를 사람이 정한다.

## 권한 — 멤버가 시작할 때의 수준

권한 체계는 **모델이 아니라 하네스** 기준으로 적용된다. GPT 모델을 Claude Code 로 돌리면 Claude Code 의 권한 체계를 쓴다.

**Claude Code 계열** — 하나를 고른다:
Default · Accept edits · Plan · Auto · Don't ask · Bypass permissions

**Codex 계열** — 두 축을 따로 정한다:
- 샌드박스: `read-only` · `workspace-write` · `danger-full-access`
- 승인 정책: `untrusted` · `on-request` · `never`
- 조합 프리셋: Read Only · Auto · Full Access · Custom
- Guardian 사용 여부

권한은 대화 중에도 바꿀 수 있고 **다음 턴부터** 적용된다.
멤버별로 저장되므로 멤버를 닫거나 앱을 껐다 켜도 그대로다.

## 승인 카드

권한이 허용하지 않는 일을 AI 가 하려 하면, 대화 안에 **승인 카드**가 뜨고 그 멤버는 거기서 멈춘다.

카드에서 보이는 것: 도구 이름과 설명, 실행하려는 명령 원문, 작업 디렉터리, 파일 diff, 요청 사유.
Codex 라면 "앞으로 항상 허용될 규칙"까지 함께 보여 준다.

고를 수 있는 것: 거부 · 이번 한 번 허용.
Codex 는 범위를 더 나눈다 — 이번 한 번 · 현재 세션 · **같은 command prefix 는 앞으로 항상** · 거부.

승인 대기 중인 멤버는 사이드바에 배지가 뜬다. 처리한 뒤에도 카드는 무슨 결정을 했는지 남긴다.

## 모델이 되묻는 질문

AI 가 사람에게 물어야 할 때 선택지 카드가 뜬다.
단일·다중 선택, 선택지 설명, 기타/직접 입력, 자유 입력, 비밀 입력.
여러 질문이면 이전/다음/건너뛰기가 있고, 필수 항목이 비면 전송이 막힌다.

## 되돌릴 수 없는 것

- **파티 삭제** — 멤버·메시지·역할 파일·디스크 저장소가 전부 사라진다. 2단 확인을 거친다.
- **대기열 모두 취소** — 빨간 버튼 + 2단 확인.
- **계정 연결 끊기** — 2단 확인. 자격 증명은 복구 가능한 백업으로 옮겨진다.

되돌릴 수 있는 것과 헷갈리지 않게: **탭 닫기**는 실행만 멈추고 멤버와 기록은 남긴다 → `party.md`

## 앱이 스스로 거절하는 것

- 대화 속 링크가 **실행 파일·스크립트**면 실행하지 않고 위치만 보여 준다 → `talk.md`
- 모델 목록 조회에 실패하면 **다른 제공자 모델로 대신 채우지 않는다**
- 인증이 없거나 플랜이 안 되면 **다른 모델로 몰래 바꾸지 않고** 오류를 낸다
- 작업공간 경로를 해석 못 하면 **비슷한 폴더로 대신 열지 않는다**

공통 원칙 하나다 — **조용한 대체보다 눈에 보이는 실패가 낫다.**
잘못된 모델로 이미 30분을 돌린 뒤에 알아채는 게 훨씬 비싸기 때문이다.
