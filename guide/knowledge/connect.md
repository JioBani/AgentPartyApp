# 계정 연결

왼쪽 메뉴 **인증**. 하나도 연결하지 않으면 멤버가 아무 말도 못 한다.

## Claude 구독

연결을 누르면 **시스템 브라우저**가 열리고 거기서 승인한다.
앱은 그동안 `인증 대기` 상태를 보여 주고, OAuth URL 을 직접 복사할 수도 있다.

연결되면 **Claude Code 와 Codex 양쪽 하네스**에서 Claude 모델을 쓸 수 있다.

연결에는 로컬 브리지가 필요하다. 앱이 시작할 때 알아서 띄우고 상태를 감시하며,
설치돼 있지 않으면 **공식 Windows 바이너리를 받아 게시된 SHA-256 을 검증한 뒤** 설치한다.

⚠ 다운로드·검증·실행이 실패하면 **다른 제공자로 대체하지 않고** 오류로 표시한다.

## Codex 구독 (ChatGPT 계정)

브라우저 OAuth 로 연결한다. 완료되면 상태가 자동으로 갱신되고,
**Codex 와 Claude Code 양쪽**에서 GPT 모델을 쓸 수 있다.
로컬과 WSL 양쪽의 Codex 인증 저장소에 반영된다.

⚠ OAuth 토큰 원문은 화면에도 HTTP API 응답에도 **노출하지 않는다.**

### 인증을 바꾸면 돌고 있던 세션은

- 유휴 세션은 재시작한 뒤 **기존 스레드를 즉시 이어받는다.**
- 응답 중인 세션은 **현재 턴이 끝난 뒤** 재시작한다.
- 영향받은 세션의 대화에는 인증이 바뀌었다는 진단이 표시된다.

## Cursor

**AgentParty 안에 Cursor 로그인·로그아웃 진입점이 없다.**
이미 설치해 로그인해 둔 로컬 Cursor Agent CLI 의 계정을 그대로 쓴다.
앱은 설치 여부와 실행 파일만 탐지하고, 없으면 미설정 또는 진단 오류로 알린다.
쓸 수 있는 모델은 그 계정의 플랜을 따른다.

## OpenRouter

API 키를 넣는다. 저장된 키는 마스킹되고, **테스트** 버튼이 실제로 API 를 호출해 확인한다
(정상 / 유효하지 않음 / 네트워크 오류).
앱 설정에 키가 없으면 환경 변수 `OPENROUTER_API_KEY` 를 쓴다.

⚠ 키 없이 OpenRouter 모델을 시작하면 **대체 없이 명시적 오류**가 난다.
⚠ 키 삭제는 HTTP API 에만 있고 인증 화면에는 버튼이 없다.

## 연결 끊기

**연결 끊기** 버튼은 실수 방지를 위해 **두 번** 눌러야 실행된다.
자격 증명은 지워지는 대신 복구 가능한 백업으로 옮겨진다.

끊은 뒤 앱은 모델 목록을 다시 조회해 **정말 끊겼는지 확인한다.**
다른 자격 증명 소스가 그 모델을 계속 제공하면 해제가 덜 됐다고 오류를 낸다.
