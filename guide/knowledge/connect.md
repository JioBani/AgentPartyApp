# 계정 연결

왼쪽 메뉴에서 **인증**을 선택한다. 연결된 계정이나 제공자가 없으면 멤버가 응답을 생성할 수 없다.

## Claude 구독

**연결**을 선택하면 시스템 브라우저가 열리며, 브라우저에서 연결을 승인한다.
연결을 진행하는 동안 앱에 `인증 대기` 상태가 표시되며, OAuth URL을 직접 복사할 수도 있다.

연결이 완료되면 **Claude Code와 Codex 하네스 모두**에서 Claude 모델을 사용할 수 있다.

연결에는 로컬 브리지가 필요하다. 앱 시작 시 브리지가 자동으로 실행되며 상태를 지속적으로 확인한다.
브리지가 설치되어 있지 않으면 **공식 Windows 바이너리를 내려받고 게시된 SHA-256을 검증한 후** 설치한다.

⚠ 다운로드·검증·실행에 실패하면 **다른 제공자로 대체하지 않고** 오류를 표시한다.

## Codex 구독 (ChatGPT 계정)

브라우저 OAuth를 통해 연결한다. 연결이 완료되면 상태가 자동으로 갱신된다.
**Codex와 Claude Code 하네스 모두**에서 GPT 모델을 사용할 수 있다.
인증 정보는 로컬 환경과 WSL 환경의 Codex 인증 저장소에 모두 반영된다.

⚠ OAuth 토큰 원문은 화면과 HTTP API 응답에 **노출되지 않는다.**

### 인증 변경 시 실행 중인 세션 처리

- 유휴 세션은 재시작 후 **기존 스레드에서 즉시 작업을 이어간다.**
- 응답 중인 세션은 **현재 턴이 끝난 후** 재시작한다.
- 영향을 받은 세션의 대화에는 인증 변경을 알리는 진단 메시지가 표시된다.

## Cursor

**AgentParty에는 Cursor 로그인·로그아웃 기능이 없다.**
로컬 Cursor Agent CLI에 로그인된 계정을 그대로 사용한다.
앱은 Cursor Agent CLI의 설치 여부와 실행 파일만 확인하며, Cursor Agent CLI가 없으면 미설정 상태 또는 진단 오류를 표시한다.
사용 가능한 모델은 해당 계정의 플랜에 따라 결정된다.

## OpenRouter

API 키를 입력한다. 저장된 키는 마스킹되며, **테스트** 버튼을 누르면 실제 API 호출을 통해 상태를 확인한다.
(정상 / 유효하지 않음 / 네트워크 오류).
앱 설정에 API 키가 없으면 환경 변수 `OPENROUTER_API_KEY`를 사용한다.

⚠ API 키 없이 OpenRouter 모델을 시작하면 다른 모델로 대체하지 않고 명시적인 오류를 표시한다.
⚠ API 키 삭제 기능은 HTTP API에서만 제공되며 인증 화면에는 해당 버튼이 없다.

## 연결 끊기

**연결 끊기** 버튼은 의도하지 않은 연결 해제를 방지하기 위해 **두 번** 선택해야 실행된다.
자격 증명은 삭제되지 않고 복구 가능한 백업 위치로 이동된다.

연결을 끊은 후 앱은 모델 목록을 다시 조회하여 **연결 해제 여부를 확인한다.**
다른 자격 증명 소스에서 해당 모델을 계속 제공하는 경우 연결이 완전히 해제되지 않았다는 오류를 표시한다.
