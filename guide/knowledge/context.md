# 컨텍스트와 세션 관리

## 컨텍스트 사용량 확인

멤버 대화창 상단의 **도넛 차트**에 해당 멤버의 컨텍스트 사용량이 표시된다.
사용한 토큰 수와 전체 컨텍스트 크기가 함께 표시되며, 사용량이 많으면 경고 색상으로 변경된다.
종료된 멤버의 마지막 사용량은 흐리게 표시되며 `~` 기호가 함께 표시된다.

⚠ 전체 컨텍스트 크기를 확인할 수 없는 모델은 **토큰 수만 표시하고 사용 비율은 표시하지 않는다.**
전체 컨텍스트 크기를 확인할 수 없으면 정확한 사용 비율을 계산할 수 없기 때문이다.

## 압축

컨텍스트 사용량을 줄여 기존 대화를 계속 진행할 수 있도록 하는 기능이다.

- **수동** — 도넛 차트를 선택하면 현재 사용량과 임계값을 확인하고 압축을 즉시 실행할 수 있다.
  활성 세션이 없으면 실행할 수 없는 사유가 표시된다.
- **자동** — 멤버별로 기능을 켜고 임계값을 10~95% 범위에서 1% 단위로 설정한다. 사용량이 임계값을 초과하면 압축을 한 번 실행한다.
  멤버별 설정이 없으면 **에이전트** 화면의 전역 기본값을 상속한다(신규 설치 시 기능은 꺼져 있으며, 저장된 기준값은 80%).

⚠ 전체 컨텍스트 크기를 확인할 수 없으면 **자동 압축을 실행하지 않는다.**
⚠ 압축 중에는 메시지 전송의 인터럽트 설정과 관계없이 압축 작업을 중단하지 않는다.

## 세션 관리

- **재시작(대화 유지)** — 하네스 스레드를 이어받아 대화 맥락과 기록을 유지한 상태로 세션을 다시 시작한다.
  변경된 모델 설정과 MCP 구성은 재시작 시 다시 적용된다.
- **하드 재시작** — 멤버 등록과 세션 정보는 유지하고 **대화 맥락만 초기화**한다.
  활성 세션이 없으면 실행할 수 없다.
- **세션 종료** — 세션 실행만 종료한다. 멤버 설정과 저장된 대화 기록은 유지된다.

⚠ **하네스가 변경되는 재시작은 새 스레드에서 진행된다.** 하네스 간 대화 ID가 호환되지 않기 때문이다.

## 대화 연속성 유지 방식

앱은 하네스의 thread ID를 저장하고, 세션을 다시 열 때 동일한 대화에 연결한다.
따라서 앱이나 세션을 재시작해도 기존 대화를 계속 진행할 수 있다.
Cursor는 chat ID를 사용하여 동일한 방식으로 대화를 연결한다.

## 세션 화면

왼쪽 메뉴의 **세션**에서 현재 실행 중인 세션과 이전 작업을 확인하고 작업을 계속할 수 있다.
