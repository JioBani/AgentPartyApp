# 대화가 길어지면 — 컨텍스트와 세션

## 컨텍스트가 얼마나 찼는지

멤버 대화창 위쪽의 **도넛**이 그 멤버의 컨텍스트 사용량이다.
쓴 토큰과 전체 크기가 같이 보이고, 많이 차면 색이 경고로 바뀐다.
닫힌 멤버는 마지막 값이 흐리게 `~` 와 함께 남는다.

⚠ 전체 컨텍스트 크기를 모르는 모델이면 **토큰 수만 보여 주고 비율을 만들지 않는다.**
모르는 분모로 퍼센트를 지어내지 않는다는 뜻이다.

## 압축

컨텍스트를 줄여 대화를 이어가는 기능이다.

- **수동** — 도넛을 클릭하면 현재 사용량과 임계 위치가 보이고 즉시 실행할 수 있다.
  세션이 없으면 왜 못 하는지 사유가 나온다.
- **자동** — 멤버별로 켜고, 임계값을 10~95% 사이 1% 단위로 정한다. 넘으면 한 번 실행된다.
  멤버에 설정이 없으면 **런타임** 화면의 전역 기본값을 물려받는다(신규 설치 기본은 꺼짐, 저장 기준값 80%).

⚠ 전체 컨텍스트 크기를 모르면 **자동 압축을 하지 않는다.**
⚠ 압축 중에는 전송 시 인터럽트 설정과 무관하게 끊지 않는다.

## 세션 다루기

- **재시작(대화 유지)** — 하네스 스레드를 이어받아 맥락과 기록을 유지한 채 다시 세운다.
  바꾼 모델 설정과 MCP 구성이 이때 다시 적용된다.
- **하드 재시작** — 멤버 등록과 세션 자리는 그대로 두고 **대화 맥락만 초기화**한다.
  활성 세션이 없으면 실행할 수 없다.
- **세션 종료** — 실행만 멈춘다. 멤버 설정과 저장된 기록은 남는다.

⚠ **하네스가 바뀌는 재시작은 새 스레드가 된다.** 대화 ID 가 호환되지 않기 때문이다.

## 대화가 이어지는 원리

앱은 하네스의 thread ID 를 저장해 두었다가 세션을 다시 열 때 같은 대화에 연결한다.
그래서 앱을 껐다 켜도, 세션을 재시작해도 "아까 하던 이야기"가 이어진다.
Cursor 는 chat ID 로 같은 일을 한다.
