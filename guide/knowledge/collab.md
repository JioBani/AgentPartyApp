# 멤버끼리 일하기

이 앱의 핵심이다. 멤버는 사람을 거치지 않고 **서로에게 메시지를 보낸다.**
사람이 A 의 답을 복사해서 B 에게 붙여넣는 일을 없애는 게 목적이다.

## 메시지 전달

- **직접 전송** — 대상 멤버를 지정해 보낸다.
- **전체 방송** — 보낸 사람을 뺀 전원에게. 멤버별로 성공/실패가 따로 나온다.
- 대화 기록에는 **발신인지 수신인지**와 **누구→누구** 경로가 함께 표시된다.

⚠ 전체 방송은 현재 주로 로컬 HTTP API 와 에이전트용 파티 도구에서 제공된다.

### 받는 쪽이 일하는 중이면

- **기본은 대기** — 지금 턴이 끝난 뒤에 읽는다.
- **interrupt** — 지금 하던 걸 끊고 즉시 넣는다. 급한 정정에 쓴다.
- 받는 쪽에 **활성 세션이 없으면** 전달이 실패로 기록된다. 조용히 사라지지 않는다.

기본값을 대기로 둔 이유는 안전이지만, 대가가 있다: 긴 턴을 도는 멤버는
**한참 뒤에야** 그 메시지를 읽는다. 그래서 이미 낡은 지시로 계속 일할 수 있다.
지금 바로 봐야 하는 말이면 interrupt 를 쓴다.

## Message Gate — 나가는 말을 검사한다

멤버가 **다른 멤버에게** 보내는 메시지를, 전달 전에 가벼운 심사 모델이 규칙에 비춰 검사한다.

- 승인되면 그대로 간다.
- 반려되면 **전달되지 않고**, 사유와 어긴 규칙이 보낸 멤버의 대화에 카드로 남는다.
- 꼭 보내야 하면 **강제 전송**할 수 있고, 우회했다는 사실이 함께 표시된다.

⚠ 사용자가 보내는 메시지는 심사 대상이 **아니다.** 멤버→멤버 발신만 본다.
⚠ 심사 모델 자체가 실패하면 **막지 않고 경고와 함께 전달한다**(fail-open).
게이트 고장이 파티 전체를 멈추게 두지 않기 위해서다.
⚠ 게이트를 켜 놓고 규칙을 비워 두면 실제로는 아무 심사도 일어나지 않는다. 앱이 그 사실을 경고한다.

**설정 순서**: 파티 단위로 켜고 규칙을 적는다 → 멤버별로 Inherit / On / Off 를 덮어쓸 수 있다.
심사 모델(리뷰어)도 멤버 → 파티 → 앱 전역 순으로 상속된다. 바꾸면 즉시 반영된다.
새 파티는 **꺼진 상태**로 시작한다.

쓰는 예 — "오케스트레이터를 거치지 말고 담당자에게 직접 말할 것", "보고는 세 줄 이내로".

## 서브에이전트

멤버가 스스로 하위 작업자를 만들어 일을 쪼갤 수 있다.
대화창 아래 **도크**에 몇 개를 만들었고 각각 실행 중·완료·실패·대기 중 어느 상태인지 나온다.

행을 클릭하면 상세로 들어간다 — **무엇을 위임했는지**, 답변, 도구 실행 결과, 걸린 시간.
상단 breadcrumb(상위 멤버 → 서브에이전트)으로 원래 대화로 돌아온다.

## AI 가 앱을 직접 조작하는 것

멤버 세션 안의 AI 는 앱의 파티 기능을 직접 실행할 수 있다 —
파티·멤버 조회, 멤버 생성·삭제, 다른 멤버에게 전송, 상태 조회, 작업 중단, 전체 방송,
권한 변경, Message Gate 변경.

AI 가 한 조작 중 **멤버 생성·삭제는 전용 카드로 대화에 기록된다.** 사람이 나중에 추적할 수 있게 하기 위해서다.

## Discord 로 밖에서 보기

봇을 연결하면 멤버가 자기 Discord 스레드를 만들어 보고 채널로 쓴다.
사용자가 그 스레드에 쓴 글은 멤버 세션으로 들어가고(유휴면 깨우고, 바쁘면 대기열에 쌓는다),
메시지에 영수증 이모지가 붙는다 — 📨 전달됨 · ⚙️ 처리 중 · ✅ 완료 · ⚠️ 지연.

`!` 로 시작하는 제어 명령(상태·연결·중단·재시작 등)은 **LLM 을 거치지 않는다.**
멤버가 응답 불능이어도 제어 명령은 동작한다.

⚠ 허용 사용자 ID 목록이 **비어 있으면 아무도** 메시지를 보낼 수 없다. 빈 목록은 "전체 허용"이 아니다.
⚠ 한 메시지는 2000자까지, 이미지는 10 MB 까지. 넘으면 잘리는 게 아니라 거부된다.
