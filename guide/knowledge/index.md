# AgentParty 가이드 지식

이 폴더가 가이드 챗봇·슬라이드 채팅이 읽는 **정본**이다.
시스템 프롬프트에 내용을 요약해 넣지 마라. **이 파일부터 읽고**, 필요한 다른 md 를 연다.

| 파일 | 다루는 것 |
|---|---|
| `screens.md` | 화면이 어디에 있는지 |
| `party.md` | 파티와 멤버 |
| `safety.md` | Message Gate · 권한 |
| `cost.md` | 비용이 어디서 나는지 |

정본에 없으면 지어내지 말고 모른다고 한다.
앱의 **지금 이 순간** 상태(내 멤버가 왜 멈췄나, 로그인이 왜 안 되나)는 여기서 답하지 않는다. 왼쪽 메뉴의 **문제 해결**로 보낸다.
