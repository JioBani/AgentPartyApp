# AgentParty 가이드 지식

이 폴더가 가이드 챗봇과 슬라이드 채팅이 읽는 **정본**이다.
시스템 프롬프트에 내용을 요약해 넣지 마라. **이 파일부터 읽고**, 질문이 닿는 다른 md 를 연다.
목차만 보고 구체적인 질문에 답하지 않는다.

## AgentParty 가 뭔가 — 한 문단

여러 AI 코딩 세션을 **한 폴더 위에서 동시에** 돌리는 데스크톱 앱이다.
세션 하나를 **멤버**라 부르고, 멤버들이 모인 것이 **파티**다.
멤버는 각자 다른 회사의 AI(Claude·GPT·Grok…)로 돌 수 있고, 사람을 거치지 않고 **서로 메시지를 주고받는다**.
사람은 그 사이에서 일을 나눠 주고, 위험한 실행을 승인하고, 결과를 본다.

## 파일 지도

| 파일 | 여기서 답할 질문 |
|---|---|
| `start.md` | 설치하고 처음 켰다. 뭐부터 하나 |
| `screens.md` | 그 화면이 어디 있나. 창·탭·패널은 어떻게 쓰나 |
| `party.md` | 파티와 멤버를 어떻게 만들고 관리하나 |
| `talk.md` | 멤버에게 말을 어떻게 거나. 첨부·중단·대기열·명령 |
| `collab.md` | 멤버끼리 어떻게 일을 주고받나. Message Gate·서브에이전트 |
| `safety.md` | 멋대로 못 하게 어떻게 막나. 권한·승인·되돌릴 수 없는 것 |
| `context.md` | 대화가 길어지면. 컨텍스트·압축·재시작 |
| `connect.md` | 계정 연결. Claude·Codex·Cursor·OpenRouter |
| `cost.md` | 돈이 어디서 나가나 |
| `limits.md` | 안 되는 것, 아직 없는 것 |

## 답할 때의 규칙

- 정본에 없으면 **지어내지 않는다.** 모른다고 하고, 어느 파일이 다뤘어야 하는지 말한다.
- 화면 이름·버튼 이름은 **사용자가 눈으로 찾을 수 있는 그대로** 쓴다.
- **되돌릴 수 없는 동작**은 절차보다 먼저 경고한다.
- 앱의 **지금 이 순간** 상태(내 멤버가 왜 멈췄나, 로그인이 왜 안 되나)는 여기서 답하지 않는다.
  왼쪽 메뉴의 **문제 해결**로 보낸다. 그쪽은 실제로 들여다볼 수 있고, 이 문서는 못 한다.
