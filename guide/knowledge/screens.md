# 화면 구성

왼쪽 탐색 메뉴(nav-rail)에 화면 목록이 다음 순서로 표시된다.

| 화면 | 주요 기능 |
|---|---|
| **Workbench** | 파티와 멤버의 작업을 관리하는 기본 화면 |
| **가이드** | 앱 사용 방법을 문의하거나 기능 동작 안내를 확인하는 화면 |
| **인증** | AI 계정 연결·해제 → `connect.md` |
| **에이전트** | 새 멤버 기본값, 입력창·메시지·압축·절전, 파티 프롬프트, Message Gate, Discord |
| **설정** | 언어·글꼴, 환경, 작업 위치, 모바일 연결, 버전, 진단, 자동화 API와 로그 |

테마 전환(밝게/어둡게)과 창 버튼은 **화면 상단의 제목 표시줄**에 있으며 설정 화면에는 포함되지 않는다.

## Workbench 구조

```
┌ 사이드바 ┬─────── 패널 ───────┬─────── 패널 ───────┐
│ 파티 목록 │ [탭][탭][+]        │ [탭]               │
│ 멤버 목록 │                    │                    │
│          │   대화 기록         │   대화 기록         │
│          │                    │                    │
│          │   입력창            │   입력창            │
└──────────┴────────────────────┴────────────────────┘
```

- **사이드바** — 현재 작업공간의 파티와 선택한 파티의 멤버를 표시한다. 사이드바를 접거나 너비를 조절할 수 있다.
- **탭** — 하나의 패널에서 여러 멤버를 전환하여 표시한다. 드래그하여 순서를 변경하거나 다른 패널로 이동할 수 있다.
- **패널** — 화면을 좌우로 분할하여 **여러 멤버를 동시에** 표시한다. 탭을 빈 영역으로 이동하면 새 패널이 생성되고, 탭이 없는 패널은 자동으로 제거된다.

화면 배치는 **파티별로 저장된다.** 파티를 다시 선택하거나 앱을 재시작해도 열린 탭·패널·비율이 복원된다.

⚠ **탭을 닫으면 해당 멤버의 세션도 종료된다.** 화면에서 탭만 제거되는 것이 아니다.
멤버 정보는 유지되므로 다시 열 수 있지만, 실행 중이던 작업은 중단된다.

패널 너비가 줄어들면 표시 형식이 자동으로 간소화된다(wide → mid → narrow). 제공되는 기능은 동일하다.

## 창

여러 창을 열 수 있으며, **창마다 서로 다른 작업공간**을 표시할 수 있다.
동일한 작업공간을 여러 창에서 열면 상태가 실시간으로 동기화된다. 한 창에서 생성한 멤버가 다른 창에도 즉시 표시된다.
