# 화면이 어디 있나

왼쪽 세로 막대(nav-rail)가 화면 목록이다. 위에서부터:

| 화면 | 여기서 하는 일 |
|---|---|
| **Workbench** | 파티와 멤버가 실제로 일하는 곳. 대부분의 시간을 여기서 보낸다 |
| **가이드** | 지금 보고 있는 것. 물어보거나, 앱이 움직이는 걸 본다 |
| **세션** | 지금 돌고 있는 세션과 지난 작업 이어가기 |
| **Token Usage** | 어디서 얼마나 썼는지 |
| **인증** | AI 계정 연결·해제 → `connect.md` |
| **런타임** | 새 멤버의 기본값, 입력창 동작, 앱 버전과 업데이트 |
| **자동화** | 로컬 API 주소, 로그 위치 |

테마 전환(밝게/어둡게)과 창 버튼은 **맨 위 제목 표시줄**에 있다. 설정 화면 안이 아니다.

## Workbench 의 구조

```
┌ 사이드바 ┬─────── 패널 ───────┬─────── 패널 ───────┐
│ 파티 목록 │ [탭][탭][+]        │ [탭]               │
│ 멤버 목록 │                    │                    │
│          │   대화 기록         │   대화 기록         │
│          │                    │                    │
│          │   입력창            │   입력창            │
└──────────┴────────────────────┴────────────────────┘
```

- **사이드바** — 이 작업공간의 파티들과, 선택한 파티의 멤버들. 접거나 폭을 조절할 수 있다.
- **탭** — 한 패널 안에 여러 멤버를 겹쳐 둔다. 드래그로 순서를 바꾸거나 다른 패널로 옮긴다.
- **패널** — 화면을 좌우로 나눠 **여러 멤버를 동시에** 본다. 탭을 빈 곳에 떨구면 새 패널이 생기고, 비면 자동으로 사라진다.

배치는 **파티별로 기억된다.** 파티를 다시 고르거나 앱을 껐다 켜도 열어 둔 탭·패널·비율이 그대로 돌아온다.

⚠ **탭을 닫으면 그 멤버의 세션도 끝난다.** 화면만 치우는 게 아니다.
멤버 자체는 남아 있으므로 다시 열면 되지만, 돌고 있던 작업은 거기서 멈춘다.

패널이 좁아지면 표시가 자동으로 간결해진다(wide → mid → narrow). 기능이 사라지는 건 아니다.

## 창

창은 여러 개 열 수 있고, **창마다 다른 작업공간**을 볼 수 있다.
같은 작업공간을 두 창에서 열면 서로 실시간으로 같은 상태를 본다 — 한쪽에서 만든 멤버가 다른 쪽에도 바로 뜬다.
