# 파티와 멤버

**멤버** = AI 세션 하나. **파티** = 같이 일하는 멤버들의 묶음.
파티는 작업공간(폴더)에 속한다. 폴더를 바꾸면 파티 목록도 바뀐다.

## 파티 만들기

사이드바에서 이름을 넣고 `+` 를 누르면 바로 생긴다. 좀 더 갖춰 만들려면 모달을 쓴다.
만들면 **`main` 멤버가 자동으로 하나** 생기고, 그 세션이 미리 준비된다.

⚠ 생성 모달은 **바깥을 클릭해도 안 닫힌다.** 쓰던 내용이 날아가지 않게 일부러 그렇게 했다.

파티를 여러 개 두고 오갈 수 있다. 사이드바에는 각 파티의 **전체 멤버 수와 지금 일하는 멤버 수**가 보인다.

## 멤버 만들기

멤버 목록의 `+` 로 마법사가 열린다. 순서는:

**이름 → 하네스 → 모델 → 추론 설정 → 권한 → 역할·확인**

- **이름** — 파티 안에서 유일해야 한다.
- **하네스** — 이 멤버를 실제로 돌릴 프로그램. Claude Code · Codex · Cursor CLI 중 하나.
- **모델** — 그 하네스에서 쓸 수 있는 모델만 보인다. 성능·비용·컨텍스트 크기·이미지 지원을 비교해 고른다.
- **추론 설정** — Effort, Thinking 모드, Thinking 토큰 예산. 그 모델이 지원하지 않는 항목은 아예 안 보인다.
- **권한** — 시작할 때 적용될 수준 → `safety.md`
- **역할** — 이 멤버가 뭘 하는 사람인지. 나중에 일을 나눌 때 기준이 된다.

만들면 새 패널이 자동으로 열린다.

⚠ 모델 목록을 못 불러오면 **다른 제공자 모델로 슬쩍 바꿔 채우지 않는다.** 실패를 그대로 보여주고 다시 시도하게 한다.

### 하네스와 모델의 관계

하네스는 "무엇으로 돌릴지", 모델은 "누가 생각할지"다. 보통은 짝이 정해져 있다(Claude Code ↔ Claude, Codex ↔ GPT).
자체 하네스가 없는 모델(OpenRouter 를 통한 GLM·Kimi·Grok·Gemini·Qwen, DeepSeek 등)은 Claude Code 나 Codex 위에서 돈다.

⚠ **베타 기간에는 교차 조합이 잠겨 있다.** Claude Code + GPT, Codex + Claude 구독,
Claude Code + Cursor 구독 세 가지는 모델 목록에 `베타 잠금` 배지와 이유가 함께 표시되고 선택이 거부된다.
위에 적은 OpenRouter·DeepSeek 모델은 잠금 대상이 **아니다** — 그게 그 모델의 유일한 실행 경로이기 때문이다.

## 멤버 상태 보기

사이드바와 패널 양쪽에 지금 상태가 나온다:
시작 전 · 준비/유휴 · 요청 중 · 응답 중 · 중단 중 · 닫힘 · 오류 · **승인 대기** · 안 읽은 메시지 수.

승인 대기는 사람이 눌러 주기 전까지 그 멤버가 멈춰 있다는 뜻이다 → `safety.md`

## 멤버 실행 구성 바꾸기

만든 뒤에도 모델·Effort·Thinking·디버그 로그·자동 압축을 바꿀 수 있다.

⚠ **첫 턴이 돌았거나 메시지가 쌓였으면 하네스는 못 바꾼다.** 하네스를 바꾸면 대화 ID 가 호환되지 않아
지금까지의 맥락이 새 스레드로 끊기기 때문이다. 같은 하네스 안에서 모델을 바꾸는 건 언제든 된다.

## 지우기 — 무엇이 얼마나 사라지나

| 동작 | 사라지는 것 | 남는 것 |
|---|---|---|
| **탭 닫기** | 그 멤버의 실행(세션) | 멤버, 대화 기록, 설정 |
| **멤버 삭제** | 멤버 등록·역할 파일·실행 | 파티의 나머지 |
| **파티 삭제** | 멤버·메시지·역할 파일·디스크 저장소 전부 | — |

⚠ **파티 삭제는 되돌릴 수 없다.** 그래서 2단 확인을 거치고, 돌고 있던 세션을 전부 먼저 끝낸다.
⚠ `main` 멤버는 삭제할 수 없다.
