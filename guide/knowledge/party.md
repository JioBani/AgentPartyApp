# 파티와 멤버

**멤버** = AI 세션 하나. **파티** = 함께 작업하는 멤버의 모음.
파티는 작업공간(폴더)에 속하며, 작업공간을 변경하면 파티 목록도 변경된다.

## 파티 만들기

사이드바에 이름을 입력하고 `+`를 선택하면 파티가 생성된다. 세부 설정이 필요한 경우 생성 모달을 사용할 수 있다.
파티를 생성하면 **`main` 멤버가 자동으로 생성되며** 해당 세션이 미리 준비된다.

⚠ 입력 내용을 보존하기 위해 생성 모달은 **외부 영역을 선택해도 닫히지 않는다.**

여러 파티를 생성하고 전환할 수 있다. 사이드바에는 각 파티의 **전체 멤버 수와 현재 작업 중인 멤버 수**가 표시된다.

## 멤버 만들기

멤버 목록의 `+`를 선택하면 생성 마법사가 열린다. 설정 순서는 다음과 같다.

**이름 → 하네스 → 모델 → 추론 설정 → 권한 → 역할·확인**

- **이름** — 파티 내에서 고유해야 한다.
- **하네스** — 멤버를 실행하는 프로그램으로, Claude Code · Codex · Cursor CLI 중에서 선택한다.
- **모델** — 선택한 하네스에서 사용할 수 있는 모델만 표시된다. 성능·비용·컨텍스트 크기·이미지 지원 여부를 비교하여 선택한다.
- **추론 설정** — Effort, Thinking 모드, Thinking 토큰 예산을 설정한다. 모델이 지원하지 않는 항목은 표시되지 않는다.
- **권한** — 시작할 때 적용될 수준 → `safety.md`
- **역할** — 멤버가 담당할 업무를 지정한다. 이후 작업을 배정할 때 기준으로 사용된다.

멤버를 생성하면 새 패널이 자동으로 열린다.

⚠ 모델 목록을 불러오지 못하면 **다른 제공자의 모델로 대체하지 않는다.** 오류를 표시하고 다시 시도할 수 있도록 안내한다.

### 하네스와 모델의 관계

하네스는 멤버를 실행할 프로그램이고, 모델은 작업을 처리할 AI다. 일반적인 조합은 Claude Code ↔ Claude, Codex ↔ GPT다.
자체 하네스가 없는 모델(OpenRouter를 통한 GLM·Kimi·Grok·Gemini·Qwen, DeepSeek 등)은 Claude Code 또는 Codex에서 실행된다.

⚠ **베타 기간에는 교차 하네스 조합이 제한된다.** Claude Code + GPT, Codex + Claude 구독,
Claude Code + Cursor 구독 세 가지는 모델 목록에 `베타 잠금` 배지와 이유가 함께 표시되고 선택이 거부된다.
위에 명시된 OpenRouter·DeepSeek 모델은 잠금 대상이 **아니다.** 해당 하네스가 이 모델들의 유일한 실행 경로이기 때문이다.

## 멤버 상태 확인

현재 상태는 사이드바와 패널에 모두 표시된다.
시작 전 · 준비/유휴 · 요청 중 · 응답 중 · 중단 중 · 닫힘 · 오류 · **승인 대기** · 안 읽은 메시지 수.

**승인 대기**는 사용자가 승인 요청을 처리할 때까지 해당 멤버의 작업이 중단된 상태를 의미한다 → `safety.md`

## 멤버 실행 설정 변경

멤버 생성 후에도 모델·Effort·Thinking·디버그 로그·자동 압축 설정을 변경할 수 있다.

⚠ **첫 턴을 실행했거나 대기 메시지가 있으면 하네스를 변경할 수 없다.** 하네스를 변경하면 대화 ID가 호환되지 않아
기존 대화 맥락을 새 스레드에서 이어갈 수 없기 때문이다. 동일한 하네스에서는 언제든 모델을 변경할 수 있다.

## 삭제 항목별 영향 범위

| 동작 | 삭제되는 항목 | 유지되는 항목 |
|---|---|---|
| **탭 닫기** | 그 멤버의 실행(세션) | 멤버, 대화 기록, 설정 |
| **멤버 삭제** | 멤버 등록·역할 파일·실행 | 파티의 나머지 |
| **파티 삭제** | 멤버·메시지·역할 파일·디스크 저장소 전부 | — |

⚠ **파티 삭제는 되돌릴 수 없다.** 두 단계의 확인 절차를 거치며, 실행 중인 모든 세션을 먼저 종료한다.
⚠ `main` 멤버는 삭제할 수 없다.
