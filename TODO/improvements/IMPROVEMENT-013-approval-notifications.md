# IMPROVEMENT-013 · 다른 파티나 최소화된 창의 승인 요청도 놓치지 않기

## 문제와 배경

현재 보지 않는 파티에서 승인이 필요하거나 앱이 최소화되면 사용자가 알 수 있는 경로가 부족하다.

## 사용자 경험

다른 일을 보는 동안에도 어떤 파티와 멤버가 승인을 기다리는지 알고 바로 해당 요청으로 이동하는 경험.

## 원하는 동작과 범위

파티 목록의 승인 표시를 기본으로 제공하고, 선택 가능한 OS 알림과 원격 알림을 단계적으로 연결한다.

## 완료 조건

- [ ] 다른 파티의 승인 대기를 파티 목록에서 확인한다.
- [ ] 표시를 누르면 해당 승인 카드로 이동한다.
- [ ] 중복·해결된 알림을 다시 보여주지 않는다.
- [ ] 알림 채널을 사용자가 켜고 끈다.

## 제외 범위와 미결 사항

OS 알림과 Discord 알림의 기본값, 민감한 도구·경로를 알림에 얼마나 표시할지는 결정 필요다.
