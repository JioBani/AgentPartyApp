# IMPROVEMENT-009 · 여러 이미지를 첨부해도 어느 것을 말하는지 쉽게 가리키기

## 문제와 배경

여러 이미지를 넣으면 사용자가 순서를 머릿속으로 세어 본문에 번호를 써야 하고, 화면 순서와 모델 전달 순서가 어긋날 위험이 있다.

## 사용자 경험

각 이미지에 번호나 설명을 붙여 정확히 지목하고 모델도 같은 대상을 이해하는 경험.

## 원하는 동작과 범위

화면 참조와 전송 순서를 일치시키며 취소·재정렬 뒤에도 참조 관계를 명확히 유지한다.

## 완료 조건

- [ ] 두 장 이상에서 화면 순서와 전달 순서가 일치한다.
- [ ] 번호 또는 설명이 썸네일에 보인다.
- [ ] 취소·재정렬 시 변화가 명확하다.
- [ ] 대기열 편집 후에도 참조가 보존된다.

## 제외 범위와 미결 사항

번호·이미지별 메모·본문 칩 중 어느 방식을 쓸지는 결정 필요다.
