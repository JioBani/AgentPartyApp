# IMPROVEMENT-011 · 디스코드 연결을 오래 켜두고도 안정적으로 제어하기

## 문제와 배경

기본 양방향 브리지는 구현됐지만 429, 장시간 재연결, 다중 인스턴스, 화이트리스트 거부 같은 실환경 공백이 남아 있다.

## 사용자 경험

폰에서 연결 상태를 믿고 장시간 보고·지시하며 실패 시 이유와 복구 방법을 아는 경험.

## 원하는 동작과 범위

실제 제한·재연결·다중 프로세스 상황을 검증하고 명령 범위와 상태 표시 정책을 확정한다.

## 완료 조건

- [ ] 실제 또는 충실한 429 재시도를 검증한다.
- [ ] 장시간 끊김과 재연결을 검증한다.
- [ ] 같은 머신 다중 인스턴스를 구분한다.
- [ ] 거부·이미지·명령 실패를 명확히 표시한다.

## 제외 범위와 미결 사항

명령 접두사, 주기 상태 갱신, 멤버 생성·권한 제어 범위는 결정 필요다.
