# IMPROVEMENT-006 · 스킬과 플러그인을 쉽게 찾고 적용 상태를 이해하기

## 문제와 배경

명령 팔레트와 카탈로그에 항목이 많지만 검색·분류·적용 상태가 충분히 명확하지 않다.

## 사용자 경험

필요한 스킬이나 플러그인을 이름과 설명으로 찾고, 어디에 적용됐는지 바로 아는 경험.

## 원하는 동작과 범위

검색·필터·출처 그룹·상세 설명·적용 상태를 공통 카탈로그 패턴으로 제공한다.

## 완료 조건

- [ ] 이름·설명·출처로 검색한다.
- [ ] 적용 가능 여부와 현재 상태를 구분한다.
- [ ] 긴 목록을 그룹화하고 키보드로 탐색한다.
- [ ] 지원되지 않는 명령은 이유를 설명한다.

## 제외 범위와 미결 사항

라이브 설치·업데이트·신뢰 권한까지 포함할지는 결정 필요다.
