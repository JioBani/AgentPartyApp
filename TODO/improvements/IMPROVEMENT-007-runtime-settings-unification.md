# IMPROVEMENT-007 · 모델과 추론 설정을 한곳에서 일관되게 고르기

## 문제와 배경

런타임 기본값 화면과 모델 카탈로그에 effort·thinking 같은 선택기가 중복되어 서로 다른 값을 고를 수 있다.

## 사용자 경험

어디서 설정하든 같은 선택지를 보고 실제 적용 값을 확신하는 경험.

## 원하는 동작과 범위

모델·추론 강도·thinking·budget·service tier를 하나의 선택 흐름과 하나의 저장 규칙으로 통합한다.

## 완료 조건

- [ ] 중복 컨트롤을 제거한다.
- [ ] 하네스별 지원 옵션만 보여준다.
- [ ] 저장 후 재열기와 새 멤버 기본값을 검증한다.
- [ ] 지원하지 않는 조합을 설명한다.

## 제외 범위와 미결 사항
