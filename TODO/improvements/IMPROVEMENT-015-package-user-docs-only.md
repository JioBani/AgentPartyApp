# IMPROVEMENT-015 · 사용자 설치본에서 내부 개발 문서를 제외하기

## 문제와 배경

패키징 설정에 따라 조사·피드백·디자인 자료 같은 내부 문서가 앱 산출물에 포함될 수 있어 설치 크기와 공개 범위가 불필요하게 커진다.

## 사용자 경험

설치본에는 앱 실행과 사용자 도움말에 필요한 자료만 들어 있어 다운로드가 가볍고 내부 작업 문서가 노출되지 않는 경험.

## 원하는 동작과 범위

패키징 허용 목록을 정하고 사용자 가이드와 런타임 필수 자산만 산출물에 포함한다.

## 완료 조건

- [ ] 패키지 안의 문서·자산 목록을 검사한다.
- [ ] 내부 조사·피드백·디자인 자료가 제외된다.
- [ ] 가이드와 라이선스 등 필수 자료는 유지된다.
- [ ] 패키징 회귀 검사를 자동화한다.

## 제외 범위와 미결 사항

저장소의 개발 문서를 삭제하는 일은 제외한다. 사용자에게 제공할 오프라인 문서 범위는 결정 필요다.
