# IMPROVEMENT-012 · 진행 중인 작업을 끊지 않고 방향을 덧붙이기

## 우선순위

**최우선** (2026-09-28 사용자 지정)

## 문제와 배경

현재 사용자는 기다리거나 턴을 중단하고 새 메시지를 우선 전달해야 한다. 하네스가 지원하는 steer와 일반 대기열의 차이가 제품에서 충분히 드러나지 않는다.

Codex와 Claude는 원래 턴 도중에 입력을 받아, 작업 중 물어보거나 사용자가 끼어들어 방향을 바꿀 수 있다. AgentParty에서는 작업 중인 멤버에게 보낸 메시지가 메시지 큐에 들어가 턴이 끝날 때까지 기다리므로 이 사용성이 사라진다. 지금 남은 선택지는 턴 종료까지 기다리기(그동안 잘못된 방향으로 계속 작업)와 인터럽트(진행 중 맥락이 끊김)뿐이다.

## 사용자 경험

진행 중 답변을 버리지 않고 짧은 추가 지시로 방향을 수정하는 경험.

## 원하는 동작과 범위

지원 하네스에서는 steer를 제공하고, 미지원 하네스에서는 대기·중단과 다른 결과를 명확히 안내한다.

1. 조사: Codex·Claude가 턴 도중 입력을 프로토콜/SDK 차원에서 어떻게 지원하는지, 입력이 모델에 언제 반영되는지, 도구 호출 중에 들어오면 어떻게 되는지 확인한다.
2. 네이티브 적용: 확인한 하네스의 방식 그대로 연결한다. 큐 대기나 인터럽트로 흉내 내지 않는다.

## 완료 조건

- [ ] 지원 하네스에서 현재 턴에 지시가 반영된다.
- [ ] 미지원 하네스에서 조용히 다른 동작으로 바뀌지 않는다.
- [ ] 대기·중단·steer가 UI에서 구분된다.
- [ ] 기록과 비용 귀속을 검증한다.

## 제외 범위와 미결 사항

하네스별 기능 차이를 완전히 같게 만드는 것은 범위 밖이다.

- 대기열 추가·지금 보내기(인터럽트)·턴에 끼워 넣기(steer) 중 기본값과, 사용자가 셋을 구분해 고르는 방법은 결정 필요다.
- 다른 멤버가 보낸 메시지도 steer로 넣을지 결정 필요다. 사용자 입력과 같은 규칙이면 다른 멤버가 작업 중인 멤버의 방향을 바꿀 수 있다.
