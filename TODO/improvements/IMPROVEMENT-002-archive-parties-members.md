# IMPROVEMENT-002 · 파티와 멤버를 삭제하지 않고 보관했다가 되돌리기

## 문제와 배경

목록을 정리하는 수단이 삭제뿐이면 대화와 설정을 잃지 않으려는 사용자는 오래된 항목을 계속 떠안게 된다.

## 사용자 경험

당장 쓰지 않는 파티나 멤버를 숨기고 필요할 때 그대로 복구하는 경험.

## 원하는 동작과 범위

보관·보관함 조회·복구를 제공하고, 영구 삭제는 명시적인 별도 동작으로 유지한다.

## 완료 조건

- [ ] 파티와 멤버를 각각 보관할 수 있다.
- [ ] 보관 후 기록과 설정이 유지된다.
- [ ] 보관함에서 복구할 수 있다.
- [ ] 실행 중 세션과 이름 충돌 정책을 검증한다.

## 제외 범위와 미결 사항

보관 시 세션 종료 방식과 보관된 이름 재사용 정책은 결정 필요다.
