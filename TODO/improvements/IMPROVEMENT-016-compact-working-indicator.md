# IMPROVEMENT-016 · "작업 중" 표시를 모델 아이콘 애니메이션으로 줄이기

## 문제와 배경

멤버가 작업 중이라는 표시(텍스트·점 표시 등)가 패널 헤더와 멤버 목록에서 별도 공간을 차지한다. 패널이 좁을수록 이 공간이 이름·모델 같은 다른 정보를 밀어낸다.

## 사용자 경험

추가 공간 없이, 이미 보이는 모델 아이콘만 보고도 어느 멤버가 일하고 있는지 알아보는 경험.

## 원하는 동작과 범위

작업 중 상태를 별도 표시 대신 멤버의 모델(하네스) 아이콘이 깜빡이거나 움직이는 방식으로 나타내도록 디자인을 바꾼다. 적용 위치는 패널 헤더와 사이드바 멤버 행을 우선으로 한다.

## 완료 조건

- [ ] 작업 중 표시가 차지하던 공간이 사라지고, 모델 아이콘의 애니메이션으로 상태를 알 수 있다.
- [ ] 애니메이션만으로 상태를 전달하지 않는다. 아이콘에 `aria-label`/툴팁으로 상태를 남긴다.
- [ ] `prefers-reduced-motion`에서는 깜빡임 대신 정적인 구분(테두리·배지 등)으로 대체한다.
- [ ] 승인 대기·멈춤·실패처럼 사용자 행동이 필요한 상태는 이 애니메이션과 구분된다.

## 제외 범위와 미결 사항

- 깜빡임·펄스·회전 중 어떤 움직임을 쓸지, 속도와 강도는 디자인 결정이 필요하다.
- 여러 멤버가 동시에 작업할 때 화면 전체가 산만해지지 않는지 확인이 필요하다.
