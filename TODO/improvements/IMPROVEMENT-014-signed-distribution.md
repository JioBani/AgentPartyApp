# IMPROVEMENT-014 · Windows 설치와 업데이트의 신뢰 경고를 줄이기

## 문제와 배경

Windows 배포본은 서명되지 않아 설치·업데이트 때 운영체제 신뢰 경고가 나타날 수 있다. 자동 업데이트 기능은 구현됐지만 설치 단계 실증과 서명 방침은 남아 있다.

## 사용자 경험

공식 설치본임을 확인하고 불필요한 보안 경고 없이 설치·업데이트하는 경험.

## 원하는 동작과 범위

현실적인 코드 서명 경로를 확정하고 설치·업데이트·회수 전 과정을 실제 배포본으로 검증한다.

## 완료 조건

- [ ] 서명 주체·인증서 보관·갱신 방침을 확정한다.
- [ ] NSIS 설치본과 업데이트 산출물을 검증한다.
- [ ] SmartScreen과 서명 정보를 실제 Windows에서 확인한다.
- [ ] 서명 실패 시 배포를 중단하거나 명확히 알린다.

## 제외 범위와 미결 사항

개인·비공개 소스 조건에서 가능한 서명 서비스와 비용은 확인 필요다. 서명 없이 배포를 계속할 경우 그 결정을 문서화한다.
