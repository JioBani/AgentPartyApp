# IMPROVEMENT-004 · 하네스나 제공자를 바꿔도 같은 대화를 이어가기

## 문제와 배경

같은 멤버에서 하네스나 제공자를 바꾸면 새 세션이 이전 맥락을 모른다.

## 사용자 경험

모델을 바꿔도 직전 대화와 작업 맥락을 자연스럽게 이어가는 경험.

## 원하는 동작과 범위

앱 트랜스크립트를 새 세션에 안전하게 재생하고, 옮기지 못한 내용은 사용자에게 밝힌다.

## 완료 조건

- [ ] Claude·Codex·Cursor 사이 대표 교체를 검증한다.
- [ ] 긴 대화의 요약·절단 결과를 표시한다.
- [ ] 이미지·도구 결과 처리 정책을 검증한다.
- [ ] 교체 후 모델이 이전 핵심 사실을 기억한다.

## 제외 범위와 미결 사항

실행 중 교체와 비텍스트 변환 규칙은 결정 필요다.
