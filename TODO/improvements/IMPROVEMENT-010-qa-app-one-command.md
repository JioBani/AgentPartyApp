# IMPROVEMENT-010 · 격리된 QA 앱을 한 명령으로 안전하게 띄우기

## 문제와 배경

확인용 앱 실행 절차가 흩어져 있어 잘못된 워크스페이스나 사용자 앱을 건드리는 사고가 있었다.

## 사용자 경험

개발자가 추론 없이 한 명령으로 격리된 확인 환경을 열고 안전하게 종료하는 경험.

## 원하는 동작과 범위

별도 userData·워크스페이스를 만들고 바인딩을 검증하며 해당 프로세스만 정리하는 명령을 제공한다.

## 완료 조건

- [ ] 단일 명령이 격리 환경을 만든다.
- [ ] 바인딩 실패 시 앱을 남기지 않고 실패한다.
- [ ] 연결 정보와 정리 방법을 출력한다.
- [ ] 사용자 앱과 데이터를 건드리지 않는다.

## 제외 범위와 미결 사항

시드 데이터와 자동 캡처 포함 여부는 결정 필요다.
