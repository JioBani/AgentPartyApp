# IMPROVEMENT-001 · 파티와 멤버 이름을 한글로도 자연스럽게 짓기

## 문제와 배경

생성 화면과 저장 키가 ASCII 이름만 허용해 사용자가 팀을 익숙한 언어로 이름 붙일 수 없다.

## 사용자 경험

파티와 멤버를 한국어 표시 이름으로 만들고 찾아서 소통하는 경험.

## 원하는 동작과 범위

표시 이름과 내부 식별자를 분리해 유니코드 이름을 보존하고 주소 충돌을 막는다.

## 완료 조건

- [ ] 한글·공백·혼합 이름을 생성하고 재시작 후 보존한다.
- [ ] 같은 표시 이름의 충돌을 안전하게 안내한다.
- [ ] 멘션·도구 주소·파일 저장이 깨지지 않는다.
- [ ] 기존 ASCII 이름과 호환된다.

## 제외 범위와 미결 사항

허용 문자 전체와 개명 기능은 아직 결정되지 않았다.
