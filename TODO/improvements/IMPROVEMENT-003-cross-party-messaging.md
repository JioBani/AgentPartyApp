# IMPROVEMENT-003 · 다른 파티의 멤버에게도 안전하게 메시지 보내기

## 문제와 배경

현재 멤버 통신은 같은 파티 안에 한정되어 목적별로 나눈 팀끼리 협업할 수 없다.

## 사용자 경험

필요할 때 파티 경계를 넘어 특정 멤버나 팀 전체에 출처가 분명한 메시지를 보내는 경험.

## 원하는 동작과 범위

파티와 멤버를 함께 식별하는 주소, 권한, 출처 표시를 갖춘 교차 파티 전송을 제공한다.

## 완료 조건

- [ ] 같은 워크스페이스의 다른 파티에 전송한다.
- [ ] 동명이인을 잘못 선택하지 않는다.
- [ ] 수신 화면에 외부 파티 출처가 보인다.
- [ ] 권한·게이트·실패 결과를 검증한다.

## 제외 범위와 미결 사항

다른 워크스페이스·프로세스까지 허용할지는 결정되지 않았다.
