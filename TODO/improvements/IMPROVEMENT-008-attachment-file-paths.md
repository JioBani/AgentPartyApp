# IMPROVEMENT-008 · 붙여넣은 이미지를 멤버가 실제 파일로 다루게 하기

## 문제와 배경

이미지 첨부는 바이트로만 전달되어 멤버가 복사·이동·이름 변경할 디스크 경로를 알 수 없다.

## 사용자 경험

이미지를 보여준 뒤 같은 파일을 프로젝트로 옮기거나 도구 입력으로 쓰라고 지시하는 경험.

## 원하는 동작과 범위

첨부를 작업공간 안에 저장하고 이미지 입력과 함께 해당 멤버가 열 수 있는 경로를 전달한다.

## 완료 조건

- [ ] Windows와 WSL에서 접근 가능한 경로를 전달한다.
- [ ] 복사·이동·리네임을 실제로 수행한다.
- [ ] 중복 파일과 정리 정책을 검증한다.
- [ ] 저장 실패를 숨기지 않는다.

## 제외 범위와 미결 사항

보존 기간·용량 상한·경로만 전달하는 모드는 결정 필요다.
