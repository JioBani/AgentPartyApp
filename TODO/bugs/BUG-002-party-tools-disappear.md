# BUG-002 · 파티 도구가 사라진 멤버를 자동으로 복구하기

## 문제와 배경

Claude CLI 내부 동시성 문제로 파티 MCP 도구가 시작부터 없거나 사용 중 사라질 수 있다. 방어 구현은 별도 브랜치에만 있고 기준 브랜치에는 통합되지 않았다.

## 사용자 경험

멤버 간 통신이 갑자기 막혀도 사용자가 세션을 버리지 않고 자동 복구 결과나 명확한 실패 안내를 받는 경험.

## 원하는 동작과 범위

도구 등록 상태와 호출 실패를 감지하고 안전하게 한 번 복구하며, 반복 실패는 숨기지 않고 안내한다.

## 완료 조건

- [ ] 시작 시 도구 미등록을 감지한다.
- [ ] 사용 중 도구 소실을 감지한다.
- [ ] 세션 재시작 후 대화가 이어지고 도구가 복구된다.
- [ ] 재시도 상한과 실패 안내를 검증한다.

## 제외 범위와 미결 사항

Claude CLI 자체 수정은 범위 밖이다. 방어 브랜치의 최신 기준 재검증이 필요하다.
