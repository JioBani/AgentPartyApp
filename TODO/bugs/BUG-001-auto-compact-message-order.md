# BUG-001 · 자동 압축 중 들어온 메시지가 순서를 벗어나지 않게 하기

## 문제와 배경

자동 압축과 메시지 대기열의 순서 보장이 실제 사용 환경에서 확인되지 않았다. 압축보다 메시지가 먼저 처리되거나 압축 중 메시지가 즉시 전달된다는 사용자 보고가 있다.

## 사용자 경험

긴 대화가 압축되는 동안 보낸 지시가 사라지거나 앞뒤가 바뀌지 않고, 압축이 끝난 뒤 정확히 한 번 처리되는 경험.

## 원하는 동작과 범위

압축 시작부터 완료까지 새 메시지는 눈에 보이는 대기 상태를 유지하고, 완료 후 입력 순서대로 한 번씩 전달한다.

## 완료 조건

- [ ] 수동·자동 압축 각각에서 재현 여부를 확인한다.
- [ ] 압축 중 여러 메시지가 대기열에 남는 것을 검증한다.
- [ ] 압축 완료 후 순서·중복·누락을 자동 테스트로 확인한다.
- [ ] 실패 시 사용자가 원인을 볼 수 있다.

## 제외 범위와 미결 사항

원인이 하나인지 두 결함인지 아직 확인 필요하다. 압축 알고리즘의 품질 개선은 별도 범위다.
