# BUG-006 · 앱이나 화면이 실패해도 사라지지 않고 복구 방법을 알려주기

## 문제와 배경

메인 프로세스의 충돌 기록은 남지만 치명적 오류 직전 사용자 안내와 React 렌더러 오류 경계는 확인되지 않았다. 앱이나 화면이 갑자기 사라지면 사용자는 원인과 로그 위치를 알기 어렵다.

## 사용자 경험

앱 전체 또는 한 화면이 실패해도 무엇이 실패했는지 알고, 기록을 보존한 채 다시 열거나 로그를 확인하는 경험.

## 원하는 동작과 범위

치명적 오류 안내, 로그 폴더 연결, 화면 단위 오류 경계와 안전한 다시 시도를 제공한다.

## 완료 조건

- [ ] 메인 프로세스 치명 오류를 사용자에게 알린다.
- [ ] 렌더러 오류가 앱 전체를 빈 화면으로 만들지 않는다.
- [ ] 로그 위치와 재시작 방법을 안내한다.
- [ ] 대화·초안·대기열 보존 여부를 실제 충돌로 검증한다.

## 제외 범위와 미결 사항

모든 외부 하네스 충돌을 자동 수정하는 것은 제외한다. OS 알림과 대화상자 중 기본 표현은 결정 필요다.
