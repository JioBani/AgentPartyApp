# BUG-004 · 좁은 패널에서도 승인 대기와 멈춤 상태를 놓치지 않게 하기

## 문제와 배경

좁은 패널과 접힌 사이드바가 겹치면 승인 대기나 멈춤 상태를 알리는 표시가 사라질 수 있다. 작업 중 점만으로는 사용자가 해야 할 행동을 구분할 수 없다.

## 사용자 경험

여러 패널을 좁게 배치해도 어느 멤버가 승인이나 조치를 기다리는지 즉시 알아보는 경험.

## 원하는 동작과 범위

폭과 사이드바 상태에 관계없이 승인 대기·멈춤·실패가 최소 한 곳에 텍스트 또는 접근 가능한 표시로 남는다.

## 완료 조건

- [ ] 3~5분할과 접힌 사이드바 조합을 검증한다.
- [ ] 승인 대기·멈춤·실패를 서로 구분한다.
- [ ] 색만으로 상태를 전달하지 않는다.
- [ ] 상태 변경이 지연 없이 반영된다.

## 제외 범위와 미결 사항

멤버 고유색 정책 전체를 다시 설계하는 일은 별도다.
