# BUG-007 · 긴 이름과 좁은 창에서도 조작할 내용을 잘리지 않게 보기

## 문제와 배경

탭과 메뉴의 일부 오버플로 결함은 고쳤지만, 긴 경로·모델명·칩과 3~5분할 조합을 아우르는 전수 검증은 완료 근거가 없다.

## 사용자 경험

창을 좁히거나 긴 이름을 사용해도 버튼·상태·승인 내용이 잘리지 않고 스크롤이나 줄바꿈으로 접근되는 경험.

## 원하는 동작과 범위

툴바, 상태 줄, 칩, 패널 헤더, 사이드바, 승인 카드, 카탈로그와 도구 카드의 가로 오버플로를 체계적으로 검사하고 고친다.

## 완료 조건

- [ ] 긴 값과 3~5분할 조합으로 대상 화면을 측정한다.
- [ ] 중요한 조작과 상태가 화면 밖으로 사라지지 않는다.
- [ ] 줄바꿈·말줄임·가로 스크롤 규칙이 일관된다.
- [ ] 대표 좁은 폭 회귀 테스트를 추가한다.

## 제외 범위와 미결 사항

모든 임의 문자열 길이를 완벽히 표시하는 것은 제외한다. 항목별 최솟값과 축약 규칙은 확인 필요다.
