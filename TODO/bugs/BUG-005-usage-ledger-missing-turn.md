# BUG-005 · 사용량과 비용이 모든 실제 턴을 빠짐없이 집계하는지 확인하기

## 문제와 배경

실제 앱 E2E에서 여섯 메시지 뒤 원장 레코드가 다섯 개만 관측됐다. 큐 병합으로 턴 수가 줄어든 정상 동작인지, 실제 턴 누락인지 아직 불명확하다.

## 사용자 경험

대시보드의 토큰과 비용이 실제 실행보다 적거나 많지 않다고 믿을 수 있는 경험.

## 원하는 동작과 범위

메시지 수가 아니라 실제 turn_complete와 원장 레코드를 안정된 turnId로 대조해 집계 정확성을 보장한다.

## 완료 조건

- [ ] 재현 시 멤버별 실제 턴 수를 기록한다.
- [ ] turn_complete와 원장을 turnId로 일대일 대조한다.
- [ ] 큐 병합과 원장 누락을 구분한다.
- [ ] 제품 결함이면 수정 후 실제 앱 E2E를 통과한다.

## 제외 범위와 미결 사항

현재는 확인 필요 상태다. 테스트 가정이 틀린 것으로 확인되면 제품 버그 없이 테스트만 고친다.
