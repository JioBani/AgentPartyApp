# IDEA-016 · 보내는 사람과 받는 상황에 맞는 통신 규칙만 적용하기

## 문제와 배경

Message Gate 규칙이 한 덩어리여서 모든 메시지마다 LLM이 적용 여부까지 추론하고, 수신자별 규칙은 반복 작성해야 한다.

## 사용자 경험

누가 누구에게 보내는지에 따라 정확한 규칙만 적용되고 불필요한 리뷰 비용과 오판이 줄어드는 경험.

## 원하는 동작과 범위

조건과 규칙을 분리하고 구조 규칙은 기계적으로, 내용 규칙만 필요한 경우 리뷰어로 평가한다.

## 완료 조건

- [ ] 발신·수신·역할 조건을 편집한다.
- [ ] 적용 조항이 없으면 리뷰 호출을 생략한다.
- [ ] 구조 거부와 내용 거부를 구분해 설명한다.
- [ ] 기존 자유 텍스트 규칙을 그대로 마이그레이션한다.

## 제외 범위와 미결 사항

정규식 중심의 복잡한 정책 언어는 제외한다. 여러 조항의 평가 방식은 결정 필요다.
