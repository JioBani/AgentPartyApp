# IDEA-002 · 파티의 업무 흐름과 공유 진행 상황을 한눈에 보기

## 문제와 배경

여러 멤버가 동시에 일하면 누가 누구와 소통하고 어떤 과제를 들고 있는지 대화창을 하나씩 열어야 알 수 있다.

## 사용자 경험

파티 전체의 진행·대기·협업 관계를 보드나 흐름도에서 훑고 필요한 멤버로 바로 이동하는 경험.

## 원하는 동작과 범위

멤버 활동, 과제, 메시지 관계를 같은 정본에서 읽어 요약 보드와 관계 보기로 제공한다.

## 완료 조건

- [ ] 멤버별 현재 과제와 상태를 표시한다.
- [ ] 멤버 간 전달 흐름을 과장 없이 보여준다.
- [ ] 항목에서 관련 대화로 이동한다.
- [ ] 오래된 상태와 현재 상태를 구분한다.

## 제외 범위와 미결 사항

프로젝트 관리 도구를 완전히 대체하거나 모델이 추정한 진척도를 사실처럼 표시하는 일은 제외한다.
