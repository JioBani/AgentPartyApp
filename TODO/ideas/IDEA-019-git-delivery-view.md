# IDEA-019 · worktree부터 PR과 CI까지 결과물 상태를 한곳에서 보기

## 문제와 배경

멤버가 브랜치 작업을 끝낸 뒤 PR·CI 상태는 외부 도구에서 따로 확인해야 한다.

## 사용자 경험

어느 변경이 어느 PR로 이어졌고 검사가 통과했는지 멤버 결과와 함께 확인하는 경험.

## 원하는 동작과 범위

worktree 격리 선택, 브랜치·커밋 연결, PR·CI 읽기 전용 상태를 단계적으로 제공한다.

## 완료 조건

- [ ] 멤버 작업 위치와 브랜치를 연결한다.
- [ ] PR과 CI 상태를 최신 시각과 함께 표시한다.
- [ ] 실패 검사에서 관련 로그로 이동한다.
- [ ] 자격증명과 저장소 권한을 분리한다.

## 제외 범위와 미결 사항

자동 병합·배포와 GitHub 외 모든 제공자 동시 지원은 제외한다.
