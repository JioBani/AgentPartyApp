# IDEA-008 · 멤버가 스티커로 상태와 분위기를 빠르게 표현하기

## 문제와 배경

여러 멤버의 짧은 상태 보고가 글로만 쌓이면 훑기 어렵고 개성이 구분되지 않는다.

## 사용자 경험

사용자가 고른 스티커 팩 안에서 멤버가 상황에 맞는 한 장을 대화에 남기는 경험.

## 원하는 동작과 범위

사용자 소유 스티커 팩, 검색 도구, 단독 메시지 렌더링, 기록 보존을 제공한다.

## 완료 조건

- [ ] 팩을 추가·활성·비활성화한다.
- [ ] 멤버가 태그와 설명으로 한 장을 선택한다.
- [ ] 스티커가 대화 이력과 재시작 뒤 남는다.
- [ ] 팩이 없으면 컨텍스트 비용이 들지 않는다.

## 제외 범위와 미결 사항

인라인 문자열 자동 치환과 앱 기본 유료 자산 제공은 제외한다.
