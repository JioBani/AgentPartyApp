# IDEA-011 · 멤버끼리 스크린샷과 이미지를 직접 보내기

## 문제와 배경

파티 메시지는 텍스트만 전달해 QA 멤버가 찍은 화면을 구현 멤버에게 넘기려면 공유 경로를 설명해야 한다.

## 사용자 경험

멤버가 다른 멤버에게 이미지와 설명을 보내고 수신자가 같은 이미지를 보고 처리하는 경험.

## 원하는 동작과 범위

엔진 경계를 넘는 이미지 저장·대기열·게이트·비전 지원 검사를 파티 메시지에 추가한다.

## 완료 조건

- [ ] Windows↔WSL 대표 조합에서 이미지를 전달한다.
- [ ] 대기열 편집·취소 동안 파일을 안전하게 보존한다.
- [ ] 비전 미지원 수신자와 broadcast 부분 실패를 설명한다.
- [ ] 크기·개수·정리 상한을 검증한다.

## 제외 범위와 미결 사항

경로 문자열만 전달하는 방식은 다른 호스트에서 동작하지 않으므로 제외한다.
