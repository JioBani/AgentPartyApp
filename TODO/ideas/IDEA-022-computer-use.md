# IDEA-022 · 멤버가 브라우저와 화면 작업을 명시적으로 사용하기

## 문제와 배경

일부 하네스는 browser/computer/image 기능을 제공하지만 앱에서 능력과 권한을 고르고 실행 결과를 감독하는 공통 흐름이 없다.

## 사용자 경험

필요한 멤버만 화면 조작 능력을 켜고 진행 장면과 승인 요구를 안전하게 감독하는 경험.

## 원하는 동작과 범위

능력 발견·토글·권한·화면 결과·중단을 하네스별 실제 지원에 맞게 제공한다.

## 완료 조건

- [ ] 지원 능력과 제한을 정확히 표시한다.
- [ ] 사용 전 범위와 권한을 확인한다.
- [ ] 진행·중단·실패를 화면에서 관측한다.
- [ ] 민감 입력과 캡처 보존 정책을 검증한다.

## 제외 범위와 미결 사항

백그라운드 무감독 결제·로그인과 모든 사이트 호환 보장은 제외한다.
