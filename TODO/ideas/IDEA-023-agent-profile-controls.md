# IDEA-023 · 멤버의 목표·기억·성격을 확인하고 조정하기

## 문제와 배경

하네스가 goals, memories, personality를 지원해도 사용자는 현재 적용 내용과 대화 비용·영향을 앱에서 관리하기 어렵다.

## 사용자 경험

멤버가 무엇을 기억하고 어떤 목표와 말투로 동작하는지 확인하고 선택적으로 바꾸는 경험.

## 원하는 동작과 범위

지원 하네스의 프로필 요소를 출처·범위·적용 시점과 함께 읽고 편집한다.

## 완료 조건

- [ ] 현재 목표·기억·성격의 출처를 표시한다.
- [ ] 변경 전 적용 범위와 다음 턴 반영 시점을 설명한다.
- [ ] 삭제·비활성화와 되돌림을 제공한다.
- [ ] 하네스 미지원 항목을 구분한다.

## 제외 범위와 미결 사항

하네스 비공개 저장소를 우회하거나 기억을 자동 공유하는 것은 제외한다.
