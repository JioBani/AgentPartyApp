# IDEA-003 · 브랜치와 파일 변경의 담당 멤버를 바로 알아보기

## 문제와 배경

병렬 작업에서는 어떤 멤버가 어느 worktree·브랜치·파일을 맡았는지 사람이 기억해야 해 충돌과 중복 조사가 생긴다.

## 사용자 경험

멤버 카드에서 작업 위치를 보고 파일 변경 이력에서 담당 대화를 추적하는 경험.

## 원하는 동작과 범위

멤버의 cwd·worktree·브랜치와 앱이 관측한 파일 변경을 연결해 출처를 표시한다.

## 완료 조건

- [ ] 멤버별 worktree·브랜치를 정확히 표시한다.
- [ ] 파일 변경에서 관련 멤버와 시점을 찾는다.
- [ ] 같은 파일의 병렬 변경을 경고한다.
- [ ] Git 밖 변경의 불확실성을 표시한다.

## 제외 범위와 미결 사항

완전한 파일 감시·저자 판정은 운영체제와 외부 도구 한계가 있어 확인 필요다.
