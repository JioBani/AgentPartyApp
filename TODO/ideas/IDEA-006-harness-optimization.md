# IDEA-006 · 대화와 비용 기록으로 작업에 맞는 하네스를 추천받기

## 문제와 배경

사용량 데이터는 쌓이지만 어떤 작업에서 어느 하네스가 빠르고 저렴하며 성공적이었는지 사용자가 직접 비교해야 한다.

## 사용자 경험

비슷한 작업의 실제 기록을 근거로 적합한 하네스·모델 후보와 이유를 추천받는 경험.

## 원하는 동작과 범위

트랜스크립트·시간·비용·실패를 개인 로컬 분석으로 묶고 선택 가능한 추천만 제시한다.

## 완료 조건

- [ ] 비교 기준과 데이터 범위를 사용자가 확인한다.
- [ ] 추천 근거와 불확실성을 표시한다.
- [ ] 조용히 모델을 바꾸지 않는다.
- [ ] 추천을 끄거나 기록을 제외할 수 있다.

## 제외 범위와 미결 사항

품질을 자동 점수화하는 기준과 민감한 대화 분석 동의는 결정 필요다.
