# IDEA-004 · 멤버 대화창을 별도 창으로 분리해 여러 모니터에서 보기

## 문제와 배경

현재 워크벤치 패널은 한 창 안에 묶여 있어 화면이 좁거나 모니터가 여러 개일 때 중요한 멤버를 독립 배치하기 어렵다.

## 사용자 경험

멤버 탭을 별도 창으로 꺼내 다른 모니터에 두고 다시 원래 워크벤치로 합치는 경험.

## 원하는 동작과 범위

동일한 멤버 상태와 초안을 공유하는 분리 창·재결합·재시작 복원을 제공한다.

## 완료 조건

- [ ] 탭을 새 창으로 분리하고 다시 붙인다.
- [ ] 두 창에서 상태·대화·초안이 동기화된다.
- [ ] 창을 닫아도 멤버 세션이 손실되지 않는다.
- [ ] 재시작 후 합리적인 배치를 복원한다.

## 제외 범위와 미결 사항

운영체제 수준 임의 도킹과 여러 앱 인스턴스 통합은 제외한다.
