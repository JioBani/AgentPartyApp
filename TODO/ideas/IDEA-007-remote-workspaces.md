# IDEA-007 · 다른 PC의 작업공간을 현재 AgentParty에서 열기

## 문제와 배경

WSL 엔진 경계는 있지만 다른 컴퓨터의 cwd를 안전하게 여는 제품 흐름은 없다.

## 사용자 경험

노트북에서 데스크톱이나 서버의 작업공간을 열고 그 위치에서 멤버를 실행·감독하는 경험.

## 원하는 동작과 범위

원격 엔진 발견·페어링·인증·연결 상태·파일 링크 변환을 갖춘 원격 작업공간을 제공한다.

## 완료 조건

- [ ] LAN 또는 안전한 터널에서 페어링한다.
- [ ] 원격 cwd에서 멤버를 실행한다.
- [ ] 자격증명과 파일 경로가 올바른 호스트에 머문다.
- [ ] 연결 단절과 재접속을 명확히 처리한다.

## 제외 범위와 미결 사항

인증 없는 자동화 API 외부 노출과 임의 인터넷 공개는 제외한다.
