# IDEA-021 · 로컬 앱에서 Codex Cloud 작업을 맡기고 결과를 받기

## 문제와 배경

로컬 멤버만으로는 장시간 작업을 PC가 켜진 동안 유지해야 하며 Codex Cloud 위임 흐름이 연결되지 않는다.

## 사용자 경험

작업을 클라우드에 맡기고 상태·결과·변경을 AgentParty에서 다시 확인하는 경험.

## 원하는 동작과 범위

저장소·브랜치·권한을 명시한 Cloud 작업 생성과 진행·결과 수신을 제공한다.

## 완료 조건

- [ ] 작업 범위와 대상 저장소를 확인 후 위임한다.
- [ ] 진행 상태와 취소 가능 여부를 표시한다.
- [ ] 결과 커밋·diff·로그를 연결한다.
- [ ] 인증 실패와 비용 정보를 숨기지 않는다.

## 제외 범위와 미결 사항

다른 클라우드 에이전트 제공자까지 동시에 일반화하는 것은 제외한다.
