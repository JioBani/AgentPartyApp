# IDEA-017 · 멤버가 바꾼 코드를 전용 화면에서 비교하고 검토하기

## 문제와 배경

파일 변경은 대화와 외부 편집기를 오가며 확인해야 해 변경 범위와 승인 판단이 끊긴다.

## 사용자 경험

멤버별 변경을 diff 화면에서 보고 파일·구간별로 검토하며 관련 대화로 돌아가는 경험.

## 원하는 동작과 범위

하네스 fileChange와 Git diff를 연결한 읽기 전용 검토 화면부터 제공한다.

## 완료 조건

- [ ] 멤버와 턴별 변경 파일을 표시한다.
- [ ] 원본과 변경 내용을 줄 단위로 비교한다.
- [ ] 관련 승인·대화로 이동한다.
- [ ] 외부에서 바뀐 내용과 최신 상태를 구분한다.

## 제외 범위와 미결 사항

부분 적용·되돌리기는 파괴 위험과 하네스별 차이 때문에 후속 범위다.
