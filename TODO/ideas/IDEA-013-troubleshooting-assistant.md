# IDEA-013 · 앱 상태를 읽고 원인과 해결 순서를 알려주는 도우미

## 문제와 배경

문서형 가이드는 살아 있는 멤버·로그인·엔진·로그 상태를 읽을 수 없어 현재 장애를 진단하지 못한다.

## 사용자 경험

문제 해결 화면에서 현재 상태를 근거로 원인 후보와 안전한 다음 행동을 안내받는 경험.

## 원하는 동작과 범위

기존 진단 API와 로그 요약을 읽는 전용 도우미를 두고, 변경 행동은 명시적 확인 뒤 실행한다.

## 완료 조건

- [ ] 앱 버전·호스트·하네스·멤버 상태를 근거로 답한다.
- [ ] 근거 없는 추측과 비밀값 노출을 막는다.
- [ ] 진단에서 관련 설정·로그 위치로 이동한다.
- [ ] 앱 자체가 뜨지 않는 경우의 외부 안내를 제공한다.

## 제외 범위와 미결 사항

범용 코딩 멤버와 같은 권한을 자동 부여하거나 무승인 복구를 실행하는 것은 제외한다.
