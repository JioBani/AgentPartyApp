# IDEA-005 · 멈춘 멤버를 직접 깨우고 한도 회복 뒤 자동 재개하기

## 문제와 배경

한도나 외부 조건 때문에 멈춘 멤버는 사용자가 상태를 확인한 뒤 다시 말을 걸어야 하며, 재개 시점을 놓치기 쉽다.

## 사용자 경험

멤버를 명시적으로 다시 실행하거나 한도 복구 시 예약된 작업이 자동으로 이어지는 경험.

## 원하는 동작과 범위

수동 깨우기와 조건 기반 재개가 같은 안전한 재개 경로를 사용하고, 실행 이유를 기록한다.

## 완료 조건

- [ ] 유휴·한도 대기 상태에서 수동 재개한다.
- [ ] 한도 복구 조건을 확인한 뒤 한 번만 자동 재개한다.
- [ ] 사용자가 예약을 취소할 수 있다.
- [ ] 재개 이유와 결과를 대화에 남긴다.

## 제외 범위와 미결 사항

실패를 무한 재시도하거나 사용자 승인 대기를 자동 통과하는 것은 제외한다.
