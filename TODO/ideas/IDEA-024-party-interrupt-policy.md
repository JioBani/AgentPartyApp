# IDEA-024 · 파티의 수신·발신 인터럽트 정책을 한눈에 설정하기

## 문제와 배경

인터럽트 설정이 멤버·세션별 화면에 흩어져 있어 파티 전체 정책을 비교하기 어렵고, 현재 멤버에 실제 적용되는 값과 그 출처도 바로 알기 어렵다.

## 사용자 경험

파티 설정 화면 하나에서 모든 멤버의 인터럽트 정책을 확인하고, 각 멤버가 메시지를 받을 때와 보낼 때의 동작을 독립적으로 조정하는 경험.

## 원하는 동작과 범위

파티 단위의 인터럽트 관리 UI에 멤버별 행과 `수신(In)`·`발신(Out)` 열을 둔다. 각 값은 `파티 기본값 상속`·`인터럽트`·`대기열` 중에서 선택하고, 현재 유효값과 값의 출처를 함께 표시한다. 파티 기본값 변경과 여러 멤버 일괄 변경도 같은 화면에서 제공한다.

- **수신(In)**: 다른 멤버가 이 멤버에게 보낸 메시지가 진행 중인 턴을 중단할지 결정한다.
- **발신(Out)**: 이 멤버가 다른 멤버에게 보내는 메시지가 수신자의 진행 중인 턴을 중단할지 결정한다.

## 완료 조건

- [ ] 파티의 모든 멤버와 수신·발신 인터럽트 정책을 한 화면에서 비교한다.
- [ ] 멤버별로 수신과 발신 정책을 독립적으로 설정한다.
- [ ] 파티 기본값, 멤버 재정의, 최종 유효값을 구분해 표시한다.
- [ ] 선택한 여러 멤버에 정책을 일괄 적용하고 상속 상태로 되돌린다.
- [ ] 실제 메시지 전송·수신 경로가 화면에 표시된 유효값과 동일하게 동작한다.

## 제외 범위와 미결 사항

단순한 턴 중단 버튼과 메시지별 일회성 `interrupt` 지정은 이 관리 UI의 대상이 아니다. 사용자→멤버 메시지를 `수신(In)`에 포함할지, 멤버 간 메시지만 다룰지는 기획 시 결정한다.
