# IDEA-012 · 터미널에서 하던 기존 대화를 새 멤버로 가져오기

## 문제와 배경

AgentParty 밖에서 진행한 Claude·Codex 등의 세션은 새 멤버를 만들 때 그대로 반입할 수 없다.

## 사용자 경험

기존 하네스 세션을 고르고 이름·역할을 붙여 파티 멤버로 이어가는 경험.

## 원하는 동작과 범위

지원 하네스의 세션 목록·미리보기·중복 소유 방지·가져오기 결과를 제공한다.

## 완료 조건

- [ ] 실제 기존 세션을 목록에서 식별한다.
- [ ] 가져온 멤버가 이전 핵심 내용을 기억한다.
- [ ] 같은 세션의 동시 소유를 막는다.
- [ ] 실패해도 원본 세션을 변경하지 않는다.

## 제외 범위와 미결 사항

하네스 간 변환과 삭제된 세션 복구는 제외한다.
