# IDEA-009 · 도구가 필요한 입력과 상태를 AgentParty 화면에서 다루기

## 문제와 배경

외부 도구가 사용자 입력·승인·상태 화면을 요구해도 현재는 텍스트 도구 호출과 별도 UI가 따로 만들어진다.

## 사용자 경험

멤버가 도구를 쓰면 필요한 폼·승인·진행 상태가 대화와 자연스럽게 연결되는 경험.

## 원하는 동작과 범위

실제 기능 하나를 기준으로 도구 요청을 공통 카드나 화면으로 표현하는 확장 패턴을 만든다.

## 완료 조건

- [ ] 첫 대상 기능의 입력·승인·결과를 UI에서 완주한다.
- [ ] UI와 자동화 API가 같은 동작을 사용한다.
- [ ] 취소·오류·재시작 상태를 보존한다.
- [ ] 외부 도구의 신뢰 경계를 표시한다.

## 제외 범위와 미결 사항

사용자 임의 UI 코드를 앱에서 실행하는 범용 프레임워크는 제외한다.
