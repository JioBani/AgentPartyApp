# IDEA-018 · 파일·미리보기·터미널을 워크벤치 안에서 함께 사용하기

## 문제와 배경

코딩 작업에 필요한 파일 탐색, 결과 미리보기, 터미널이 앱 밖에 흩어져 멤버 대화와 작업 맥락이 분리된다.

## 사용자 경험

현재 멤버의 cwd를 기준으로 파일·미리보기·터미널을 필요한 패널에 열어 함께 보는 경험.

## 원하는 동작과 범위

워크벤치 탭 체계에 파일 탐색, 안전한 미리보기, 명시적으로 시작하는 터미널을 추가한다.

## 완료 조건

- [ ] 현재 멤버 cwd와 패널의 대상이 일치한다.
- [ ] Windows·WSL 경로를 올바르게 처리한다.
- [ ] 탭 배치와 재시작 복원을 지원한다.
- [ ] 터미널 권한과 종료 상태를 명확히 표시한다.

## 제외 범위와 미결 사항

완전한 IDE 편집기와 디버거를 내장하는 것은 제외한다.
