# IDEA-015 · 캔버스에서 멤버와 협업 관계를 연결해 파티 설계하기

## 문제와 배경

텍스트 역할과 설정 목록만으로는 팀의 역할·보고·소통 구조를 이해하고 편집하기 어렵다.

## 사용자 경험

멤버 노드를 놓고 관계를 연결해 팀 구성을 눈으로 만들고 실행 흐름까지 이어 보는 경험.

## 원하는 동작과 범위

파티 멤버·역할·연결 규칙을 편집하는 제한된 협업 캔버스를 제공한다.

## 완료 조건

- [ ] 노드로 멤버를 추가·편집·배치한다.
- [ ] 연결에 소통 목적과 규칙을 지정한다.
- [ ] 저장한 구성이 실제 파티와 일치한다.
- [ ] 실행 중 과업 흐름을 같은 도식에서 확인한다.

## 제외 범위와 미결 사항

범용 그래프 편집기나 자유로운 실행 코드 작성 도구로 확장하는 것은 제외한다.
