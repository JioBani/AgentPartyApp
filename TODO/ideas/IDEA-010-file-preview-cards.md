# IDEA-010 · 파일 내용을 다시 출력하지 않고 대화에서 미리보기

## 문제와 배경

이미 존재하는 파일을 사람이 보려고 할 때 멤버가 내용을 답변으로 다시 출력하면 비용과 트랜스크립트 용량이 불필요하게 커진다.

## 사용자 경험

대화의 파일 카드에서 필요한 줄을 보고 원본을 열되 모델 출력 토큰은 쓰지 않는 경험.

## 원하는 동작과 범위

앱이나 원격 엔진이 파일을 읽어 경로·범위·미리보기를 표시하고 컨텍스트에는 최소 참조만 남긴다.

## 완료 조건

- [ ] 텍스트 파일의 지정 범위를 미리 본다.
- [ ] 원본 파일과 줄 위치를 연다.
- [ ] WSL·원격 경로에서 동작한다.
- [ ] 거대·바이너리 파일의 제한 이유를 표시한다.

## 제외 범위와 미결 사항

멤버가 판단을 위해 파일을 읽는 입력 토큰까지 없애는 기능은 아니다.
