# IDEA-025 · 기존 파티의 이름을 언제든 수정하기

## 문제와 배경

파티를 만든 뒤에는 이름을 바꿀 수 없어 오타가 있거나 파티의 목적이 달라져도 기존 이름을 계속 사용해야 한다. 이름만 고치기 위해 파티를 다시 만들면 멤버, 세션, 탭 배치와 작업 기록을 옮겨야 하므로 비용이 지나치게 크다.

## 사용자 경험

파티 목록이나 파티 설정에서 이름 변경을 선택하고 새 이름을 저장하면, 파티를 다시 만들거나 작업을 중단하지 않고 모든 화면에 새 이름이 바로 반영되는 경험.

## 원하는 동작과 범위

기존 파티의 표시 이름만 수정한다. 파티 ID와 저장 위치, 멤버·세션·탭 그룹·대화 기록은 그대로 유지한다. 변경 결과는 현재 창뿐 아니라 같은 파티를 표시하는 다른 창과 파티 목록에도 즉시 반영하고, 앱을 재시작한 뒤에도 유지한다.

UI와 로컬 자동화 HTTP API는 같은 애플리케이션 동작을 사용한다. 빈 이름이나 저장 실패는 조용히 무시하지 않고 사용자가 바로 이해할 수 있는 오류로 표시한다.

## 완료 조건

- [ ] 파티 목록 또는 파티 설정에서 기존 파티의 이름을 수정한다.
- [ ] 앞뒤 공백을 정리하고 빈 이름을 저장하지 않는다.
- [ ] 이름 변경 중에도 파티 ID, 저장 위치, 멤버, 세션, 탭 배치와 대화 기록이 유지된다.
- [ ] 열려 있는 모든 창과 파티 이름 표시 영역에 변경 결과가 즉시 반영된다.
- [ ] 앱을 재시작해도 변경한 이름이 유지된다.
- [ ] UI와 로컬 자동화 HTTP API에서 같은 이름 변경 동작과 검증을 사용한다.
- [ ] 충돌이나 저장 실패를 사용자에게 명확히 알리고 기존 이름을 보존한다.

## 제외 범위와 미결 사항

파티 ID나 파티 저장 디렉터리 이름 변경은 범위에서 제외한다. 같은 이름의 파티를 허용할지와 이름 길이·금지 문자 규칙은 구현 전에 현재 생성 규칙과 함께 확정한다.
