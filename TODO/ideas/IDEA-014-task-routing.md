# IDEA-014 · 한 창구에 과업을 말하면 알맞은 멤버에게 직접 위임하기

## 문제와 배경

사용자가 팀 구성을 알고 오케스트레이터를 거쳐야 하므로 요청 전달과 결과 중계에 컨텍스트가 낭비된다.

## 사용자 경험

할 일을 한 번 설명하면 담당 멤버가 직접 받아 처리하고 사용자는 같은 흐름에서 결과를 보는 경험.

## 원하는 동작과 범위

과업 중심 라우팅, 담당 선택 근거, 직접 대화 연결, 책임과 상태 표시를 제공한다.

## 완료 조건

- [ ] 요청에 맞는 후보와 선택 이유를 보여준다.
- [ ] 사용자가 담당을 바꿀 수 있다.
- [ ] 중계 복사 없이 담당 대화로 연결한다.
- [ ] 실패·재위임·완료 책임을 추적한다.

## 제외 범위와 미결 사항

사용자 몰래 파티 구조나 모델을 바꾸는 자동 최적화는 제외한다.
