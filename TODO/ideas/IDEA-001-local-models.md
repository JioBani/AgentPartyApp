# IDEA-001 · Ollama나 LM Studio의 로컬 모델을 멤버로 선택해 사용하기

## 문제와 배경

AgentParty는 구독·원격 제공자 중심이며 Ollama, LM Studio, vLLM, llama.cpp 같은 로컬 추론 서버를 하나의 멤버 실행 경로로 연결하는 기반이 없다.

## 사용자 경험

데이터를 외부로 보내지 않거나 추가 API 비용 없이, 내 PC·서버의 모델을 다른 멤버와 같은 방식으로 선택해 쓰는 경험.

## 원하는 동작과 범위

OpenAI 호환 또는 제공자별 로컬 엔드포인트를 등록하고 모델 발견·연결 점검·기능 표시·실행을 제공한다.

## 완료 조건

- [ ] Ollama와 OpenAI 호환 서버 한 종류 이상을 연결한다.
- [ ] 모델 목록을 발견하거나 수동 등록한다.
- [ ] 연결 실패·컨텍스트·비전·도구 지원을 정확히 표시한다.
- [ ] Windows·WSL·원격 주소에서 대표 턴을 검증한다.

## 제외 범위와 미결 사항

서버 설치·모델 다운로드를 앱이 맡을지, 각 런타임의 채팅 템플릿까지 지원할지는 결정 필요다.
